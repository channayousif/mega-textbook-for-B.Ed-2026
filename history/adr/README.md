# Architecture decisions

An architecture decision record (ADR) captures a significant choice, its reasoning and its consequences for this repository. The crew regenerates this register weekly from the ADR files so contributors can find the present rules and their history. The full ADR is authoritative whenever this summary differs; a recorded Proposed status is preserved here and is not an acceptance claim.

## Current state by area

### Platform and hosting

The reading platform is Docusaurus with Git-versioned MDX, autogenerated navigation and local search ([ADR-0002](0002-content-platform-architecture-and-hosting.md)). Application state runs in self-hosted Supabase on project-controlled infrastructure ([ADR-0006](0006-self-hosted-supabase-backend.md)). Production uses pull-based deployment gated on CI for the exact commit ([ADR-0008](0008-production-deployment-architecture.md)); the canonical site, API and sender domains moved to textbook.com.pk ([ADR-0016](0016-primary-domain-migration-to-textbook-com-pk.md)). Usage guides have a separate docs instance, recorded as Proposed ([ADR-0009](0009-separate-docusaurus-docs-instance-for-usage-guides.md)).

### Content structure and standards

Scaffold all eight degree semesters and prioritise authoring semesters 1–4 ([ADR-0001](0001-content-scaffold-scope-scaffold-all-8-semesters-prioritize-content-for-semesters-1-4.md)). Catalog schemas and build gates enforce integrity ([ADR-0004](0004-content-integrity-build-gate-and-data-driven-catalog.md)); depth means complete concept coverage and scholarly engagement rather than a word floor ([ADR-0010](0010-content-depth-standard-and-reusable-unit-authoring-skill.md)). New units can use per-topic learning cycles and bounded public self-study answers, while the legacy layout remains supported ([ADR-0011](0011-nested-per-topic-unit-pedagogy-bounded-answer-keys-and-figure-markers.md)). Degree and licence content have distinct tracks and shared traversal ([ADR-0020](0020-content-tracks.md)). English-first publication with an untranslated banner is the current constitutional rule; its originating ADR still says Proposed ([ADR-0022](0022-english-first-corpus-with-deferred-urdu-parity.md)).

### Figures and visuals

The Figure component and manifest carry the prompt-only → generated → placed lifecycle ([ADR-0012](0012-figure-rendering-component-manifest-lifecycle-and-the-generate-figures-skill.md)). New-shape topics need at least two figures and each unit needs a concept-map, flowchart or timeline ([ADR-0017](0017-visual-density-standard-and-figure-archetype-taxonomy.md)). Schematics use committed light and dark variants, a published token palette and site-theme switching ([ADR-0018](0018-figure-theming-palette-and-generated-standard-prose.md)). The capability split ([ADR-0024](0024-capability-based-claude-and-codex-visual-authoring.md)) is amended by [ADR-0029](0029-gemini-agy-raster-illustration-producer.md) for Gemini via agy as default raster producer, with Codex as alternative, and by [ADR-0030](0030-crew-replaces-paperclip-control-plane.md) for Codex as primary SVG author with Claude, agy and opencode fallbacks. Pedagogical acceptance and independent review remain separate from generation.

### Review, evidence and publication

Independent G3/G5 certification requires qualification, protected signing and fresh evidence; agent findings alone cannot certify ([ADR-0019](0019-independent-agents-for-g3-g5-review.md)). Proposed review-led quality and authoring consultation approaches remain labelled Proposed ([ADR-0021](0021-quality-enforcement-moves-from-specification-to-review.md), [ADR-0023](0023-agent-review-substitutes-for-owner-confirmation-during-authoring.md)). Publication is distinct from certification: passing unsigned review supports the provisional notice ([ADR-0025](0025-provisional-agent-review-publication-tier.md)), and deterministic gate evidence supports the unreviewed draft notice under recorded authority ([ADR-0026](0026-publish-on-deterministic-gates.md)). ADR-0026 also records D-2026-0045's later publication delegation and permanent disclaimer. Evidence binds unit-specific inputs while retaining shared standards and conservative fallback binding ([ADR-0027](0027-unit-scoped-evidence-binding.md)).

### People, authentication and reader workflows

Teacher self-selection at signup grants peer-teaching access; restricted material requires admin-granted verified_teacher ([ADR-0005](0005-self-selectable-teacher-role-with-verified-teacher-gate.md)). Database RLS and guarded profile fields enforce access, with live profile state rather than JWT role claims ([ADR-0007](0007-authentication-and-authorization-architecture.md)). Reader feedback uses a dedicated table with server-stamped identity ([ADR-0013](0013-reader-feedback-dedicated-table-and-in-house-passage-capture.md)). Checklists hydrate by structural position with account persistence ([ADR-0014](0014-self-assessment-checklist-position-keyed-dom-hydration.md)); catalog edits download a replacement file for the normal Git review flow ([ADR-0015](0015-curriculum-owner-catalog-edits-download-and-commit-flow.md)).

### Orchestration

The repo-native crew replaces paused Paperclip, derives jobs from repository state, uses isolated worktrees and quota fallback chains, and preserves review independence ([ADR-0030](0030-crew-replaces-paperclip-control-plane.md)). Protected-path changes, including this register, go to the owner rather than automatic merge. ADR-0030 also amends ADR-0024's SVG authorship rule.
