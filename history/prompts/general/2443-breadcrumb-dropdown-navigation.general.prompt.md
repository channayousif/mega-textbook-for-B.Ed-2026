## Prompt

further I want to transform side bar int horizontal bread crumbs style drop-down menus to save space and select topics more gracefully instead of current tree style. the sidebar items are also to be reordered so that it starts from b.Ed and teaching license options menu (drop-down) style.

## Response snapshot

Owner rulings: hide the tree by default with a toggle to open it; put a sticky bar under the navbar; on phones the bar scrolls sideways and each dropdown opens as a bottom sheet. Built `CourseNavBar`, which renders in place of the doc breadcrumbs: [Programme] › [Semester] › [Course] › [Unit] › [Page], each segment a dropdown of its siblings, with the current item marked. The programme segment switches between B.Ed (`/intro`) and Teaching licence (`/licence/`). The navbar's "Licence track" link became a "Programmes" dropdown placed first. DocRoot/Layout was ejected: the tree sidebar is no longer rendered until "All topics" opens it, and the choice persists in localStorage. The sidebar labeller now takes a topic's number from its path when the title lacks it, and parses a bare "2.1 Title".
