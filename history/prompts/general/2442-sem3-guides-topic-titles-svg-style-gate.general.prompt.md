## Response snapshot

Investigated on origin/main 977533e29 and found four root causes. Owner rulings: one gates PR with a single G2 refresh; title rule in skills and gate, not the style guide; SVG lint gate and broken-file fixes now, figure kit later. This PR carries the gate half.

1. Course guide: `CourseGuideNotice` returns null for a course missing from `catalog/course-guides.json`, which lists Semesters 1-2 only. The Semester 3 guide exists only as `Scheme-and-Course-guides/3rd 2026.docx`. The JSON comment claimed validate-content enforced the link; nothing did. Added `checkCourseGuide` to validate-content (B.Ed track only): it currently fails EFMP-406 and GISS-401 until the PDFs are cut.
2. Topic numbering: file names, topic_no and topic_label were right; `title` and H1 drifted in four styles across 10 of 12 Semester 3 units and some Semester 2 units. The `Topic N.M - X` convention was never written down. It is now a validate-content rule (topic_label == unit.topic, title lead, H1 == title), stated in the author-unit, structure-standard and translate-unit skills and in both crew briefs. 51 topic files were normalised (title and H1 lines only).
3. SVG quality: new `check:svg-style` gate (content tier, CI step), with a ratchet baseline of 462 grandfathered files. It checks undefined classes, `class=""`, font-size and stroke scales, font stacks, canvas width, and marker shapes outside their own viewBox. Repaired 33 figures with undefined classes (black panels and gridlines, invisible wordmarks, the `hink` typo) and 13 Urdu figures whose arrowheads an older RTL mirror had moved off their marker viewBox. Also fixed 8 geng-301 wordmarks overflowing the edge and one gict-300 Urdu caption spill. Rendered samples in light and dark and inspected them.
