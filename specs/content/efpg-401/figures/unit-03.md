# EFPG-401 Unit 3 - Figure manifest

Figure-manifest-v2 contract (`specs/009-figure-rendering/contracts/figure-manifest-v2.md`). Twelve hand-authored schematic SVGs rendered and placed; dark variants are derived via `npm run figures:variants`. Visual density floor met with two schematics per topic and four required schematics (one flowchart, one concept-map, two diagrams).
