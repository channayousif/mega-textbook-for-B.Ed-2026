HOW THE RENDER RAN

  it serves only the default locale, so every /ur/ route returned the not-found
  page (probe-route.mjs, probe-ur-home.mjs document this). The dev server was
  stopped and the production build used instead.
- Production build of both locales inside the worktree: npm run build (exit 0,
  build.txt; static output under build/ur/...). The build failure recorded by the G3
  run001 report (unit-03 bare '<' parsed as JSX) has since been repaired; the site
  builds statically.
- Served with: npx docusaurus serve --port 3218 (serve.txt).
- Browser: Chromium via playwright-core (same engine the repo's
  scripts/measure-figure-text.mjs uses). No stable-channel Chrome and no image
  display are available to this agent, so inspection is DOM-measurement,
  geometry-measurement and pixel-analysis based; all screenshots are saved as
  evidence for human eyeballing.
- Viewports: desktop 1280x900; narrow 360x740 at deviceScaleFactor 2, isMobile,
  hasTouch; print via emulateMedia media=print at 794x1123 (A4 width).
- Pages inspected (all six): /ur/semester-1/gqur-300/unit-02/{,topic-01/,topic-02/,

FINDINGS
1. RTL and language: every page renders with <html dir="rtl" lang="ur">; headings
   and prose in Urdu; h1 matches each file's title frontmatter.
2. Nastaliq: the self-hosted Noto Nastaliq Urdu 400 webfont is the only loaded font
   and is the computed prose font on all six pages; document.fonts.check returns
   true for the full article text of topic-01 (4000-character probe) and for a
   sample of the unit's mathematical vocabulary, so every Urdu glyph in the prose is
   covered by the Nastaliq face (no tofu). See font-coverage.txt.
3. Layout: documentElement horizontal overflow is 0 px on all six pages at desktop
   1280, narrow 360 and print emulation 794 (render-inspection.json). No element
   exceeds the viewport at 360 px.
4. Print: navbar and sidebar compute display:none under print media on all six
   pages; the answers/marking-guidance section remains present in print (established
   teacher-handout posture).
5. Figures: each topic page wires exactly two figure images to the .ur.svg variants
   (light visible, .ur.dark.svg present but display:none until dark theme), carrying
   Urdu alt text. Figure label content verified against the English SVGs: all six
   Urdu variants translate the labels faithfully and the horizontal layout is
   mirrored per style-guide v4.1 (row-label column rightmost in the two tables;
   flowchart branches and the tile-growth sequence read right to left; wordmark
   moved to the left edge). Light/dark Urdu twins carry identical labels.
6. FAILURE - clipped figure text: static/img/figures/gqur-300/unit-02/fig-U2-1.ur.svg
   and fig-U2-1.ur.dark.svg anchor the side note "0 کو تمام عدد گنا جاتا ہے" at
   x=84 with text-anchor="end", so the glyphs run leftward from x=84; the in-browser
   getBBox measures the note's glyph box at x1=-40.7..x2=84.3 (y 417..432) in the
   780x470 viewBox, i.e. about 40 px of the note is cut off at the left edge.
   Pixel analysis of the standalone render finds ink in columns 0-2 at the note's
   rows (pixel-clip-standalone.txt, fig-U2-1-ur-standalone.png). The English
   fig-U2-1.svg carries the G3-repaired placement (x=84, text-anchor="start",
   extending rightward, safe); the Urdu variant swapped the anchor to "end" but did
   not reflect x about the viewBox centre (a true mirror of the repaired English
   placement is x=696, text-anchor="end"), so the note falls off the canvas. The
   repo's scripts/measure-figure-text.mjs passes because it checks only the right
   and bottom edges, and check:figures passes because it measures no glyph
   geometry. Repair: re-place the note at the mirrored position (or any safe
   anchor), then re-measure both Urdu variants.
7. Mixed-script rendering probes (render-inspection.json): the untranslated English
   word "tutors" renders inside Urdu prose on topic-01, topic-02 and topic-03 (and
   in the teacher-notes frontmatter summary); the Cyrillic word "запاس" renders in
   topic-03's mini-rubric and the unit-assessment ERQ-3 rubric; the broken word
   "شرbat" (Arabic-script شر + Latin "bat") renders in the teacher-notes sherbat
   demonstration. The intentional Latin embeds (sqrt(64), 8^2, MCQ/RRQ/ERQ labels,
   citation names/URLs) render as expected.
8. Numerals: Western digits are used consistently inside RTL prose (e.g. 3,500،
   0.75، 17,600) and render without overflow; ratio notation uses the Urdu "بہ"
   ("18 بہ 12") consistently with the prose.
9. Platform observation (not a unit defect): the sidebar/breadcrumb category label
   renders in English ("Unit 2 · Numbers and Operations") on the Urdu pages because
   no Urdu tree in the corpus carries a translated _category_.json. The draft badge
   itself renders in Urdu ("مسودہ - ماہرانہ نظرثانی باقی ہے").
