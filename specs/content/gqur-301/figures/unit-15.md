## Content corrections (generate-figures, 2026-10-23)

Recorded under ADR-0024 so the prompt and alt text changes are traceable. Each one brings a figure
into line with the worked example it sits beside; no unit prose was changed.

  72 ± 1.96 × 1.69 = 68.69 and 75.31. The mean of 75 is inside the upper cutoff (p = 0.075), so
  the old alt text "falls in the right tail" contradicted the topic's "do not reject" decision.
  Prompt and alt now name both cutoffs and place 75 inside them.
- **fig-U15-3** (G3 crew-20261023 F2): Topic 15.2 runs a right-tailed test with z = 1.84 and
  rejects H0 (p = 0.0329). The old prompt drew a two-tailed test with z = 1.82 in the "do not
  reject" region. Prompt and alt now show the right-tailed critical value 1.645 and z = 1.84 in
  the rejection region.
- **fig-U15-5**: shading moved from "±2.0" to the df = 14 critical value ±2.145 that Topic 15.3
  uses, with the z critical values ±1.96 marked for contrast. Alt text unchanged.
