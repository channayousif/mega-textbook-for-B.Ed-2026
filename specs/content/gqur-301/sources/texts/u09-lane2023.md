# Unit 9 bound reading notes: Lane

Lane, D. M. (2023, compilation year in approved course bibliography). *Online Statistics Education: A Multimedia Course of Study*. Chapter 5, Basic Concepts. https://onlinestatbook.com/2/probability/basic.html

Read 2026-10-21. These are original paraphrased notes, not a verbatim excerpt.

The counting rule depends on equally likely outcomes. Event complements use one minus the event probability. Independent trials allow multiplication of marginal chances. The balancing misconception is discussed through repeated coin tosses: a run does not change the next independent trial's chance. Supports U9-01 and U9-02. The unit substitutes original paper-slip and school scenarios for the source's examples.
