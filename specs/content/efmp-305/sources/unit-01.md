# Sources consulted - EFMP-305 Unit 1 (Foundations of Inclusive Education)

Per `specs/007-content-depth-standard/contracts/sources-consulted.md`. Every key cited in
`specs/content/efmp-305/coverage/unit-01.md` appears here, and every key here is cited both in
prose and in a per-topic `## Further reading` section.

Recorded at G1 spec stage as binding targets. Under `D-2026-0001` an unretrievable source
may be flagged and passed, but a source the authoring host cannot open binds the author to
title-and-bibliographic-level support only. The binding floor is two verifiable open-access
sources per unit (`content-spec.md`, `## Reading list`); gaps are closed at G2 source-binding,
not filled with unverified substitutes.

## Unverifiable sources

G1 stage: to be verified at G2.

- `unesco2020`: supports U1-1, U1-2. The authoring host cannot retrieve the full text;
  the prose uses it for definition-level support only (what inclusive education means, the
  inclusion spectrum). A reviewer must verify each specific claim against the source text.
- `miles2010`: supports U1-1. The DOI resolves but the host cannot access the full text;
  used for title-and-catalogue-level support only.
- `ainscow2020`: supports U1-3, U1-5. The DOI resolves but full text is not accessible from
  the host; used for the principles-of-inclusion framework and the misconceptions discussion.
- `hehir2016`: supports U1-5. Open-access report; the host cannot retrieve it for
  verification. Used for the claim that well-implemented inclusion does not reduce achievement.
- `rpwd2018`: supports U1-4. A public statute; the host cannot verify the exact wording of
  provisions cited.
- `unCRPD`: supports U1-4. A public instrument; the host cannot verify the exact wording cited.
