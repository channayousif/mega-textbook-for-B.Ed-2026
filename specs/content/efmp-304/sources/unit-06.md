# Sources consulted - EFMP-304 Unit 6

## Unverifiable sources

All mapped sources for this unit are print monographs with no DOI and no open-access edition. The
authoring host cannot retrieve the full text of any of them, so the prose uses each for
**title-and-catalogue-level support only**. Same limitation as Units 1 to 5.

- `jasper2003`: print monograph (Nelson Thornes, 2003), no DOI. Supports: journal purpose, structure,
  failure modes, descriptive vs reflective writing.
- `pendrey2022`: print monograph (Routledge, 2022), no DOI. **Scope caution: explicitly early years.**
  Used for method only, never for claims about secondary classrooms.
- `brookfield2017`: print monograph (Jossey-Bass, 2nd ed., 2017), no DOI. Supports: standards applied
  to journal entries, course-level synthesis.
- `taggart2005`: print monograph (Corwin Press, 2nd ed., 2005), no DOI. Supports: structural elements,
  prompts, marking expectations.
