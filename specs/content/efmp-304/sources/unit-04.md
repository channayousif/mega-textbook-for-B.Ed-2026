# Sources consulted - EFMP-304 Unit 4

## Unverifiable sources

All mapped sources for this unit are print monographs with no DOI and no open-access edition. The
authoring host cannot retrieve the full text of any of them, so the prose uses each for
**title-and-catalogue-level support only** unless otherwise noted below. This is the same limitation
recorded for Units 1 to 3 and flagged at course level in `content-spec.md`'s `## Reading list`.

- `jasper2003`: print monograph (Nelson Thornes, 2003), no DOI. Supports: reflective thinking as
  purposeful thinking, what a journal is and is not.
- `boud2013`: print monograph (Routledge, 2013), no DOI. Supports: U4-01 - experience alone
  does not produce learning; a process is required to turn it into learning.
- `brookfield2017`: print monograph (Jossey-Bass, 2nd ed., 2017), no DOI. Supports: reflective practice
  as sustained habit, the analysis stage, the four lenses, the critical strand.
- `osterman2004`: print monograph (Corwin Press, 2nd ed., 2004), no DOI. Supports: the reflective
  process as mechanism, evidence for claims, the cycle stages.
- `pendrey2022`: print monograph (Routledge, 2022), no DOI. **Scope caution: explicitly early years.**
  Used for method only, never for claims about secondary classrooms. Supports: U4-03.
- `taggart2005`: print monograph (Corwin Press, 2nd ed., 2005), no DOI. Supports: the levels-of-
reflection framework, activities per model, marker expectations.
