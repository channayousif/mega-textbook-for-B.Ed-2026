## Unverifiable sources

- `bassham2010`: the course's only mapped source is a print monograph (McGraw-Hill, 2010) with
  no DOI and is not open access; the authoring host cannot retrieve the full text, so the prose
  uses it for title-and-catalogue-level support only (what critical thinking is, the standards,
  the barriers, the units of reasoning). This leaves every specific claim that needs the source
  text unchecked against it - a reviewer must verify each before this unit is certified. The
  content-spec's curated-supplementary (open-access) section is deliberately empty and records a
  binding requirement that Units 1 to 3 each bind at least two verifiable open-access sources
  before authoring (`content-spec.md`, `## Reading list`); that gap is to be closed at G2
  source-binding, not filled with an unverified substitute (Constitution Art. III.5;
  `D-2026-0001`). This is the same failure mode the content-spec warns is the single biggest
  risk on this course.
