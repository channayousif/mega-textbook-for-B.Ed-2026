# Sources consulted - EFMP-304 Unit 5

## Unverifiable sources

All mapped sources for this unit are print monographs with no DOI and no open-access edition. The
authoring host cannot retrieve the full text of any of them, so the prose uses each for
**title-and-catalogue-level support only**. Same limitation as Units 1 to 4.

- `boud2013`: print monograph (Routledge, 2013), no DOI. Supports: the three-stage experiential-
  learning mechanism.
- `brookfield2017`: print monograph (Jossey-Bass, 2nd ed., 2017), no DOI. Supports: the critical
  strand, the four lenses, model comparison.
- `osterman2004`: print monograph (Corwin Press, 2nd ed., 2004), no DOI. Supports: the cycle applied
  to teaching, the return arrow.
- `taggart2005`: print monograph (Corwin Press, 2nd ed., 2005), no DOI. Supports: theoretical origins,
  model comparison, choosing.
