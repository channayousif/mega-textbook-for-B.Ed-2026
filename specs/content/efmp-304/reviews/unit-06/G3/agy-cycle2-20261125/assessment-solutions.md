## Independent MCQ Solutions

1. *(Remember)* A reflective journal is best described as a document that:
   - Options: A) Records teaching events day by day, B) Examines teaching experience in order to learn from it, C) Prepares the teacher for the next lesson, D) Maps curriculum coverage across a term.
   - Independent solution: B (A describes a diary, C a lesson plan, D a scheme of work).
   - Key in unit-assessment.mdx:183: B. Match: PASS.

2. *(Understand)* The difference between a diary and a reflective journal is that:
   - Options: A) A diary is longer than a journal, B) A diary records events; a journal analyses them, C) A diary is written by hand; a journal is typed, D) There is no difference.
   - Independent solution: B (analysis vs recounting events).
   - Key in unit-assessment.mdx:184: B. Match: PASS.

3. *(Apply)* A trainee writes, "Taught chapter 5. Pupils were noisy. Gave extra work." This is best described as:
   - Options: A) A reflective journal entry at the evidence-tested level, B) A diary entry, C) A reflective journal entry at the assumption level, D) A scheme of work.
   - Independent solution: B (pure descriptive recount without analysis).
   - Key in unit-assessment.mdx:185: B. Match: PASS.

4. *(Remember)* The four structural elements a reflective journal for assessment needs include all of the following EXCEPT:
   - Options: A) A consistent format, B) A regular schedule, C) A link between entries, D) A different model for each entry.
   - Independent solution: D (consistency is required; using a different model each time is an antipattern).
   - Key in unit-assessment.mdx:186: D. Match: PASS.

5. *(Apply)* A journal has entries every week, all using Gibbs, but each entry is unrelated to the previous one. What is missing?
   - Options: A) A consistent format, B) The return arrow (link between entries), C) A regular schedule, D) Nothing - the journal is fine.
   - Independent solution: B (missing link / return arrow connecting entries).
   - Key in unit-assessment.mdx:187: B. Match: PASS.

6. *(Understand)* "Loss of honesty" as a failure mode means that the teacher:
   - Options: A) Forgets to write, B) Starts writing what the supervisor wants rather than what actually happened, C) Uses too many models, D) Writes too little.
   - Independent solution: B (writing to impress supervisor rather than authentic learning).
   - Key in unit-assessment.mdx:188: B. Match: PASS.

7. *(Apply)* A journal entry reads, "The pupils did not understand. I think it is because the worksheet was too long." This entry is at which level?
   - Options: A) Descriptive, B) Reflective with assumption (not tested), C) Reflective with evidence-tested assumption, D) Not a journal entry.
   - Independent solution: B (identifies hypothesis/assumption without testing against data).
   - Key in unit-assessment.mdx:189: B. Match: PASS.

8. *(Remember)* Which of the following is a deepening prompt?
   - Options: A) "What did I teach today?", B) "What evidence supports what I am saying?", C) "What is tomorrow's lesson?", D) "How many pupils were present?".
   - Independent solution: B (deepens analysis through evidence).
   - Key in unit-assessment.mdx:190: B. Match: PASS.

9. *(Understand)* The logic of Units 1 to 3 and the practice of Units 4 to 6 meet in the journal because:

   - Key in unit-assessment.mdx:191: B. Match: PASS.
