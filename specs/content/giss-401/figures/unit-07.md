# GISS-401 Unit 7 - Figure manifest

Three figures planned in the content-spec Figure plan (one concept-map, one table, one flowchart); all are schematics, none is an illustration. Authored as hand-written SVG by the author job (Claude, the generate-figures fallback author), optimised with `optimize:figure --svg`, with dark variants derived by `figures:variants`, and placed. Light sources were rendered with token values substituted (sharp/librsvg, non-browser) and inspected; two geometry faults found that way (a table header running into the next column, a flowchart box past the right edge) were fixed. `scripts/measure-figure-text.mjs` was not run because the crew brief bars Chromium, so CI's `figure-geometry` job is the first measured check. Urdu `.ur.svg` localisation belongs to the separate Urdu job. fig-U7-5 is a prompt-only raster illustration of the topic's classroom situation, planned under ADR-0029 point 5 and left for the illustrate job; the unit banner is in `unit-07.banner.md`.
