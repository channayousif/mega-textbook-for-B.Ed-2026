## RRQ derived answers

1. Three properties: captured not commanded (novelty/contrast/meaning/emotion pull the
   beam; e.g. writing the day's question on the board before the wedding band starts);
   divides only at a price (copying while listening - the harder task pays; e.g.
   "copy this while I explain" yields notes without understanding); tires (depletes
   with use, worst in hot rooms/after lunch/last period; e.g. moving hardest listening
   to the first period).
2. Perception is active: the teacher has met the diagram a hundred times so it reads
   as unambiguous to them, while the class reads it through expectation without those
   encounters; the teacher's perception hides the material's difficulty. Remedy: name
   the parts / arrange more encounters.
3. Sensory memory: holds raw impressions up to ~2 seconds, job is selection-decision;
   working memory: small active workbench (~4 items, seconds to a minute) where
   thinking happens; long-term memory: unlimited archive keeping what encoding
   connected.
4. Working memory holds only a handful of items for seconds unless kept alive; four
   instruction steps plus a new question overflow the workbench, so the question is
   displaced - a full workbench, not a defective pupil.
5. Encoding: input of information into memory, connecting to what is known (effortful);
   storage: retention of the encoded, cemented by connections, strengthened by
   spacing; retrieval: recovering stored material into awareness, strengthened by
   practice.
6. Decay -> spacing; interference -> distinctiveness; retrieval failure -> retrieval
   practice.
7. Recognition = judging familiarity ("I have seen this"); recall = producing the
   material unaided ("I can produce this"). Examinations ask for production, so only
   recall serves them.
8. Any three of: algorithm (long-division steps; guaranteed, slow); heuristic
   ("draw the situation", "try a simpler case"; fast, fallible); means-ends analysis
   (compare current state to goal, shrink the gap; Ayesha's bars); working backwards
   (start from what is asked); analogy (treat this problem like a known one; transfer).
9. Inductive: cases -> rule ("this teacher always marks late"; remedy a
   counter-example); deductive: rule -> case ("if the test is Friday and today is
   Thursday, then..."; remedy showing the step).
10. E.g. (line 1) open with the question named and givens listed - aims the beam,
    offloads the workbench; (line 2) class tries one strategy aloud and names it -
    strategies become concepts; (line 3) two-minute retrieval opener on the same
    problem days later - spaced retrieval.
