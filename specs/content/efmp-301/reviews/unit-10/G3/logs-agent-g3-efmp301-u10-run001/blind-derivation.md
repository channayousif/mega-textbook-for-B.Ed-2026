   investigation). Model answer matches.

   activity (chosen to produce the evidence). Matches.
6. Mager pass/fail: pass = behaviour + condition + criterion ("adds unlike fractions
   using a diagram, five of six sums"); fail = "understands fractions" (no behaviour).
   Matches.
7. Evidence before activity, validity: an assessment designed before the activity tests
   the outcome rather than whatever the activity happens to ask. Matches

   activity changes. Matches.
9. Four observable practices: plans backward; runs the formative cycle; aims attention

   Matches (model lists six, "any four of").
