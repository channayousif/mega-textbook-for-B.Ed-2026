## C1: Workers run gates before content-status.json exists
- **Kind:** brief / skill
- **Cause:** `static/content-status.json` is a git-ignored build artifact absent in fresh worktrees and invalidated after git operations; running `npm run check:content` without building it first fails `check:content-status`, leading workers to attempt incorrect git recovery commands.
- **Recurrence:** 21 board failures, 33 missing log errors, 41 stale log errors, and 61 gate failure logs in 24 h.
- **Evidence:** log:efmp-301-u01-review_ur.2.log, log:efmp-302-u02-repair_en-conflict1.1.log, log:efmp-302-u02-repair_en-conflict4.1.log, job:efmp-305-u00-salvage, job:efmp-304-u02-review_en
- **Proposed home:** crew brief "Done when" step or `scripts/crew/crew.mjs` (`prepareWorktree` runs `npm run build:content-status` at worktree setup).
- **Signature:** `✗ <path> is missing. run: npm run build:content-status`
- **Registry:** matches candidate I-0007 (raises its recurrence).
