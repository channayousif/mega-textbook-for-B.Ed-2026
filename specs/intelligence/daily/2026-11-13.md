## C1: CLI stream truncation annotation fractures identical quota exhaustion errors into duplicate clusters
- **Kind:** crew fix
- **Cause:** When Google Gemini quota is exhausted during an `agy` worker run, the CLI streams an error ending with `(response may be truncated)` alongside a JSON-formatted `AGY_ERROR: {"short_error":"RESOURCE_EXHAUSTED (code 429)...}`. In `scripts/crew/intel.mjs`, `normalise()` strips numbers, SHAs, URLs, and paths, but retains trailing CLI stream annotations like `(response may be truncated)`. This prevents identical quota exhaustion signals from folding into the established `I-0013` cluster signature (`error: individual quota reached. please upgrade your subscription to increase your limits. resets in nhnmns.`), spawning a fragmented 1-count duplicate cluster. Additionally, `logSignals()` extracts both the raw stderr line and the structured JSON `AGY_ERROR`, causing duplicate counting for a single quota exhaustion event.
- **Recurrence:** 1 recent log error in the window (`log:efmp-301-u02-plan_illustrations.1.log`), resulting in 2 separate clusters for the same exhaustion event (1 under raw text with truncated suffix, 1 under `agy_error`).
- **Evidence:** `log:efmp-301-u02-plan_illustrations.1.log`; `scripts/crew/intel.mjs:26-39`; `scripts/crew/workers.mjs:74-87`.
- **Proposed home:** `scripts/crew/intel.mjs` (`normalise`): strip trailing CLI stream artifacts such as `\s*\((?:response may be )?truncated\)` during signature normalisation so quota exhaustion variants fold into their canonical signature, and deduplicate JSON/text pairs in `logSignals()`.
- **Signature:** `error: individual quota reached. please upgrade your subscription to increase your limits. resets in nhnmns. (response may be truncated)`
- **Registry:** matches adopted I-0013 (provides evidence of worker cooldown efficacy and identifies signature normalisation gap).

## C3: Long-duration quota exhaustion resets cool workers for up to weekly maximums
- **Kind:** crew fix
- **Cause:** When an API account hits weekly or tier limits, `agy` reports reset times exceeding multiple days (e.g. `resets in 161h27m31s`, or 6.7 days). In `scripts/crew/workers.mjs`, `resetMinutes()` accurately parses multi-hour durations up to the 10,080-minute (7-day) cap and cools the worker for 9,688 minutes without expending job attempts. While this successfully preserves job retry counts and allows alternative workers in the chain (such as `claude`) to pick up the job and land it in batch PR #544, it effectively takes the affected worker family offline for a full week, necessitating monitoring of multi-worker stage redundancy.
- **Recurrence:** 1 recent log error in the window (`efmp-301-u02-plan_illustrations.1.log`), 5 total `agy_error` resource exhaustion errors since 2026-10-21 (with reset durations of 42h, 48h, 62h, 63h, and 161h).

- **Proposed home:** `scripts/crew/workers.mjs` (`STAGES`): ensure every production stage has at least two healthy model families in its fallback chain so multi-day cooldowns on one provider do not halt stage throughput.
- **Signature:** `agy_error: {"short_error":"resource_exhausted (code n): individual quota reached. please upgrade your subscription to increase your limits. resets in nhnmns.","`
- **Registry:** matches adopted I-0013 (demonstrates that `resetMinutes` correctly calculated a 9,688-minute cooldown and preserved attempt counts, while highlighting stage chain dependency).

## C4: Summary table conflicts in course tasks.md trigger 5-fix merge ceilings and red-gate authoring jobs
- **Kind:** crew fix
- **Cause:** When multiple unit authoring branches complete concurrently within the same course (e.g. EFPG-401), branches conflict with `main` on `specs/content/<course>/tasks.md`. In `scripts/crew/batch.mjs`, `mergeTrackerRows()` only merges table rows keyed by both `Unit` and `Stage` columns. Because the top `## Units` summary table lacks a `Stage` column, it is treated as plain text lines, causing row-key resolution to return null. Jobs dispatched to fix merge conflicts manually resolve the file, but subsequent concurrent lands re-conflict `tasks.md`, eventually hitting the 5-fix limit and permanently failing ready jobs (e.g. EFPG-401 U3 and U5).
- **Recurrence:** 2 jobs permanently failed with 5-fix ceilings (`efpg-401-u03-author`, `efpg-401-u05-author`), 15 historical ceiling failures, and 150 batch exclusions since 2026-10-28.
- **Evidence:** `job:intel-2026-11-12-distill`; `job:efpg-401-u03-author`; `job:efpg-401-u05-author`; `scripts/crew/batch.mjs:124-131`.
- **Proposed home:** `scripts/crew/batch.mjs` (`mergeTrackerRows`): extend table row keying to tables keyed by `Unit` column alone when `Stage` is absent, and auto-synthesize the course `## Status:` header.
- **Signature:** `cn documents n authoring jobs (<course> un, un) permanently aborted at n merge fixes due to unkeyed <code> summary table conflicts in course <code>.`
- **Registry:** matches proposed I-0021 (re-confirmed by distill echo; raises priority of PR #498).

## C5: Local Playwright font advance discrepancy produces false-positive SVG geometry passes
- **Kind:** gate or check
- **Cause:** Local Playwright running on dev environments resolves narrower Nastaliq font metrics than the fallback font stack available on GitHub Actions CI runners (`ubuntu-latest`). Consequently, `scripts/heavy.sh node scripts/measure-figure-text.mjs <svgs>` passes locally (even at 14px font size), but CI's `figure-geometry` gate fails on pull requests due to horizontal label overflow or column collisions (e.g. PR #536 header overlap by 6.9px, PR #539 heading overlap by 57.8px), requiring iterative PR fix passes.
- **Recurrence:** 2 batch CI fix jobs (`batch-20261110-1800-cifix1`, `batch-20261110-2101-cifix1`), 2 PR failures (PR #536, PR #539).
- **Evidence:** `job:intel-2026-11-12-distill`; `job:batch-20261110-1800-cifix1`; `job:batch-20261110-2101-cifix1`; `phr:history/prompts/general/20261192-fix-pr536-urdu-figure-spacing.general.prompt.md`; `phr:history/prompts/general/20261193-fix-pr539-urdu-figure-geometry.general.prompt.md`.
- **Proposed home:** `scripts/measure-figure-text.mjs`: enforce a safety margin/tolerance buffer for Urdu Nastaliq text metrics when measuring on local hosts, or add a simulated fallback font test mode to prevent narrower local font resolutions from escaping into PR CI.
- **Signature:** `cn highlights local playwright font advances resolving narrower than ci fallback fonts, causing false-positive local geometry passes on urdu svgs.`
- **Registry:** matches proposed I-0020 (demonstrates necessity of font metric parity).
