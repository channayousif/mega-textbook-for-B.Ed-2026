## C1: Course design files under specs/content/<course>/design/ miss unit-scoping regex, binding to every unit and invalidating all sibling review manifests
- **Kind:** gate or check
- **Cause:** In `scripts/lib/review-evidence.mjs:306`, `inScope` matches unit-specific paths using `const named = /(?:^|\/)unit-(\d+)(?:\.|\/|$)/.exec(path.slice(coursePrefix.length));`. If a design file is named `unit-02-assessment.md` or `unit-02-activity-design.md`, the character following `unit-02` is a hyphen (`-`), not a dot, slash, or end-of-string. The regex fails to match, and line 307 (`if (!named) return true;`) falls through to treat the file as course-wide. Consequently, Unit 2 design files bind to every unit's G2/G3 manifest. In EFMP-406, authoring or touching Unit 2 design files invalidated the G2 evidence of Units 1, 3, 4, 5, and 6, forcing repetitive evidence re-runs across sibling branches.
- **Recurrence:** 2 handoff notes in 24 h (`job:efmp-406-u02-author-conflict4`, `job:efmp-406-u02-author-conflict5`), 1 PHR failure mode (`phr:history/prompts/general/20261107-unblock-efmp406-u02-u06-batch-conflicts.general.prompt.md`), and 1 batch exclusion loop.
- **Evidence:** job:efmp-406-u02-author-conflict4; job:efmp-406-u02-author-conflict5; job:efmp-406-u06-author-conflict4; phr:history/prompts/general/20261107-unblock-efmp406-u02-u06-batch-conflicts.general.prompt.md; `scripts/lib/review-evidence.mjs:306-309`.
- **Proposed home:** Gate or check fix in `scripts/lib/review-evidence.mjs` (`inScope`): change regex from `/(?:^|\/)unit-(\d+)(?:\.|\/|$)/` to `/(?:^|\/)unit-(\d+)(?:[-._/]|$)/` so hyphenated unit artifact names are correctly partitioned.
- **Signature:** `unit n design files under <code> still bind to every unit's manifest (<code> names miss the unit-scoping regex); unit n's gn evidence was refreshed to absorb th`
- **Registry:** new.

## C2: Source excerpt keys with hyphenated topic slugs are excluded from unit review manifests by overly restrictive citation regex
- **Kind:** gate or check
- **Cause:** In `scripts/lib/review-evidence.mjs:350`, `citedKeysFor` extracts citation keys from coverage and sources tables using `/\b([a-z][a-z-]*\d{4}[a-z]?)\b/g`. Primary source excerpts often use hyphenated descriptive slugs following the publication year (for example, `hassan-2020-two-nation`, `iqbal-1930-allahabad`, `jinnah-1940-lahore`, `jinnah-1947-assembly`, `minott-2011-critical`). Because the regex matches only `hassan-2020` or `iqbal-1930`, `citedKeys.has(excerpt[1])` in `inScope` evaluates to false. These committed primary source excerpt files under `sources/texts/` are silently excluded from the unit's input manifest, leaving a blind spot where source texts can change without invalidating dependent reviews.
- **Recurrence:** 2 review findings in 24 h; 3 total since 2026-10-28 across GPKS-402 and GNAS-301.
- **Evidence:** review:specs/content/gpks-402/reviews/unit-01/G3/b35aebba-1391-47ae-88ff-481fd326cd8b.json; review:specs/content/gnas-301/reviews/unit-05/G3/20261102T140729Z-g3-desk-6da9f991.json; review:specs/content/gpks-402/reviews/unit-01/G3/20261102T140729Z-g3-desk-b1f9d57a.json; job:efmp-406-u05-author-conflict4; `scripts/lib/review-evidence.mjs:343-350`.
- **Proposed home:** Gate or check fix in `scripts/lib/review-evidence.mjs` (`citedKeysFor`): update the regex to allow trailing hyphenated descriptor slugs (such as `/\b([a-z][a-z-]*\d{4}[a-z]?(?:-[a-z0-9-]+)?)\b/g`) or match against existing filenames in `sources/texts/`.
- **Signature:** `un-bound excerpt keys in manifest tooling`
- **Registry:** new.
