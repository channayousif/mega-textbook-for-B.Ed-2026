## C1: Untracking content-status caused git checkout pathspec crash in tick.sh, stalling cron for ~16h
- **Kind:** brief / planner fix
- **Cause:** Maintenance task M1 (`774b74d5`) untracked `static/content-status.json` from git. However, `scripts/crew/tick.sh` retained an unguarded pre-merge `git checkout -q -- static/content-status.json`. Under `set -euo pipefail`, checking out a non-tracked path threw `fatal: path 'static/content-status.json' exists on disk, but not in 'HEAD'` / `error: pathspec 'static/content-status.json' did not match any file(s) known to git`. This aborted 63 consecutive ticks (~16 hours silent cron stall) before `tick.sh` could reach the planner or stall detector. Concurrently, active branches from earlier sessions modifying the file suffered modify/delete merge conflicts when merging main (codex preserved local content-status in stash). Resolved in PR #335 by making the checkout tolerant (`2>/dev/null || true`).
- **Recurrence:** 1 pathspec error (2 total), 1 modify/delete handoff, 1 stash handoff, 1 stale error (106 total), 2 missing errors (76 total), 3 content-status gate failures (146 total), and PHRs 0873/0874 recording a ~16h cron stall.
- **Evidence:** log:efmp-304-u01-repair_en-conflict4.2.log; log:maint-2026-w43-m1-conflict1.1.log; job:maint-2026-w43-m3-conflict1; job:maint-2026-w43-survey; phr:history/prompts/general/0873-crew-status-tick-dead-pathspec.general.prompt.md; phr:history/prompts/general/0874-fix-crew-tick-pathspec-and-run-tick.general.prompt.md.
- **Proposed home:** Dispatcher script `scripts/crew/tick.sh` (tolerant checkout) and `resolveSharedConflicts` in `scripts/crew/crew.mjs` (auto-resolve modify/delete conflicts on untracked generated files).
- **Signature:** `fatal: path '<path>' exists on disk, but not in 'head'`
- **Registry:** candidate I-0007 / I-0009 (raises recurrence; evidence for post-untracking edge cases).
