# Flow prompt library

Prompts that worked, kept so the next pack starts from them. One entry per prompt: the shot type, the
filled formula block (from `prompt-formula.md`), the mode and model, and one line on why it worked.
Remove an entry when a newer one does the same job better.

Naming for clips: `<topic-slug>_<scene##>_<shot##>_<character>_<v#>.mp4` (for example
`efmp-301-u04-t1_s02_sh03_sami_v2.mp4`). Clips live in `$MEDIA_ROOT/packs/<course>/<unit>/<topic>/shots/`.
