# اپنے گریڈز پڑھیں

آپ کا **گریڈز** ایریا (ڈیش بورڈ کا حصہ) ہر کلاس میں چیک کی گئی ہر اسائنمنٹ
اور کوئز کو ان کے نمبر اور زیادہ سے زیادہ ممکنہ نمبر کے ساتھ فہرست کرتا ہے۔
آپ کا ڈیش بورڈ ہوم بھی آپ کے 5 حالیہ ترین نتائج کا پیش منظر دکھاتا ہے۔

کچھ چیزیں ہر جگہ درست ہیں جہاں آپ کے گریڈز دکھائے جاتے ہیں:

- کوئی کلاس یا گروپ کا اوسط کبھی بھی آپ کے نمبر کے ساتھ نہیں دکھایا جاتا -
  صرف آپ کا اپنا نتیجہ۔
- اگر استاد گریڈ واپس کرنے کے بعد اسے درست کرتا ہے، تو آپ ہمیشہ درست شدہ
  قدر دیکھتے ہیں، کبھی اصل نہیں۔
- کوئز اسکور آپ کے کوشش جمع کراتے ہی خود بخود شمار ہو جاتے ہیں؛ اسائنمنٹ کے
  نمبر آپ کے استاد کے کام چیک کرنے کے بعد ظاہر ہوتے ہیں۔
