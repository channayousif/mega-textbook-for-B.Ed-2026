# ڈیش بورڈ استعمال کریں

طالب علم کے طور پر سائن ان ہونے کے بعد نیوی بار میں "ڈیش بورڈ" لنک سے آپ کا
ڈیش بورڈ قابل رسائی ہے، اور اس کے چھ حصے ہیں:

## ہوم

پہلی اسکرین جو آپ دیکھتے ہیں: آپ کا موجودہ سمسٹر (آپ کی فعال کلاسوں میں سب
سے زیادہ سمسٹر)، وہ کلاسیں جن میں آپ داخل ہیں، جلد واجب کوئی بھی کام (48
گھنٹوں کے اندر واجب اشیاء پہلے فہرست ہوتی ہیں)، اور آپ کے 5 حالیہ ترین
گریڈز۔ اگر کچھ بھی واجب نہیں، تو یہ خالی جگہ دکھانے کی بجائے صاف طور پر یہ
بتاتا ہے۔

## اسائنمنٹس

آپ کی تمام فعال کلاسوں میں ہر شائع شدہ اسائنمنٹ اور کوئز جو آپ نے ابھی تک
مکمل نہیں کیا، جلد ترین واجب پہلے۔ وقت گزرے ہوئے آئٹمز واضح طور پر نشان زد
ہوتے ہیں، اور ہر ایک بتاتا ہے کہ آیا تاخیر سے جمع کرانا اب بھی قبول ہے یا
وقت ختم ہو گیا ہے — بند شدہ آئٹم کبھی بھی ایسی چیز کے طور پر نہیں دکھایا
جاتا جس پر آپ اب بھی عمل کر سکتے ہیں۔

## گریڈز

ہر واپس کیا گیا نمبر، کہیں بھی کوئی کلاس یا گروپ کا اوسط دکھائے بغیر۔ درست
شدہ گریڈ ہمیشہ درست شدہ قدر دکھاتا ہے۔

## پیش رفت

ہر کورس کے لیے، آپ نے اس کے کتنے یونٹس مکمل کیے ہیں — گریڈڈ کام، کوئز، یا
اپنے خود نشان زد کرنے کے ذریعے — ایک سادہ حصے کے طور پر (مثلاً "8 میں سے 4
یونٹس")، ساتھ ہی یہ کہ آپ کے کتنے کورسز میں کوئی پیش رفت دکھائی گئی ہے۔ آپ
اس صفحے سے، یا درسی کتاب میں اس یونٹ کے اپنے صفحے سے، کسی بھی یونٹ کو
"پڑھا ہوا" نشان زد کر سکتے ہیں — کسی بھی طرح، ایک یونٹ آپ کی پیش رفت میں
صرف ایک بار شمار ہوتا ہے، چاہے آپ اسے کتنی بار یا کتنے مختلف طریقوں سے
مکمل کریں۔

## ماضی کا ریکارڈ

جب کسی کلاس کا سمسٹر ختم ہو جاتا ہے اور وہ محفوظ کر دی جاتی ہے، تو یہ یہاں
منتقل ہو جاتی ہے — اس سمسٹر کی کلاسوں، گریڈز، اور پیش رفت کا ایک منجمد،
صرف پڑھنے کے قابل ریکارڈ بالکل ویسا جیسا اس وقت تھا۔ یہاں کچھ بھی ترمیم یا
دوبارہ جمع نہیں کیا جا سکتا۔

## کامیابیاں

ہر طالب علم کے لیے چار سنگ میل دستیاب ہیں: آپ کی پہلی جمع کرائی، مسلسل 3
دن خود مطالعہ، کسی کورس میں 100% کوریج تک پہنچنا، اور کسی کلاس کی تمام
اسائنمنٹس وقت پر مکمل کرنا۔ حاصل شدہ بیجز کو ایسا نشان زد کیا جاتا ہے؛
جن کو آپ نے ابھی حاصل نہیں کیا، یہ صفحہ بتاتا ہے کہ انہیں کیسے حاصل کریں۔
نیا حاصل شدہ بیج ہوم پر ایک چھوٹے پیش منظر کے طور پر بھی ظاہر ہوتا ہے۔
