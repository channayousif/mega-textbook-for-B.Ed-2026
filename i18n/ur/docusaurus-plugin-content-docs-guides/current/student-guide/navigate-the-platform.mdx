# پلیٹ فارم پر تشریف لے جائیں

سائٹ پر دو طرح کے صفحات ہیں:

- **درسی کتاب** - سمسٹر، پھر کورس، پھر یونٹ کے مطابق ترتیب دی گئی ہے۔ کسی بھی
  یونٹ کا مواد، سرگرمیاں اور تشخیصات تلاش کرنے کے لیے سائیڈ بار یا سرچ استعمال
  کریں۔
- **آپ کے ذاتی صفحات** - سائن ان ہونے کے بعد نیوی بار سے قابل رسائی: "ڈیش
  بورڈ" (آپ کی کلاسیں، اسائنمنٹس، گریڈز، پیش رفت، ماضی کا ریکارڈ، اور
  کامیابیاں) اور "رہنما" (یہی رہنما)۔

انگریزی اور اردو کے درمیان کسی بھی وقت تبدیل ہونے کے لیے اوپر دائیں کونے میں
زبان کا ڈراپ ڈاؤن استعمال کریں - ہر صفحہ، بشمول آپ کا ڈیش بورڈ، دونوں زبانوں
میں درست دائیں سے بائیں ترتیب کے ساتھ ظاہر ہوتا ہے۔

اگر آپ استاد یا ایڈمن کے طور پر سائن ان ہیں اور غلطی سے طلبہ کا ڈیش بورڈ
کھولتے ہیں، تو آپ کو ایک خراب صفحے کی بجائے اپنے ٹولز کی طرف اشارہ کرنے والا
نوٹس نظر آئے گا۔
