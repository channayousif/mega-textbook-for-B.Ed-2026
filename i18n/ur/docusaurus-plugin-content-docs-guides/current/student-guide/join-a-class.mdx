# کلاس میں شامل ہوں

آپ کا استاد آپ کو اپنی کلاس کے لیے ایک مختصر جوائن کوڈ دے گا۔ اسے استعمال
کرنے کے لیے:

1. ایپ نیویگیشن سے **کلاسیں** پر جائیں اور "کلاس میں شامل ہوں" منتخب کریں۔
2. کوڈ بالکل ویسے ہی درج کریں جیسے دیا گیا ہے۔
3. اگر کوڈ درست ہے، تو آپ فوری طور پر داخل ہو جاتے ہیں اور کلاس آپ کی فہرست
   میں - بشمول آپ کے ڈیش بورڈ کے ہوم ایریا میں - ظاہر ہوتی ہے۔

اگر کوڈ کام نہیں کرتا، تو اپنے استاد سے دوبارہ تصدیق کریں - ایک ہی پیغام اس
وقت ظاہر ہوتا ہے چاہے کوڈ غلط لکھا گیا ہو، ختم ہو چکا ہو، یا کسی محفوظ شدہ
کلاس سے تعلق رکھتا ہو، تاکہ کوڈ اندازہ لگانے والے اجنبی کو کچھ بھی ظاہر نہ
ہو۔

اگر آپ کو پہلے آپ کے استاد نے کسی کلاس سے ہٹا دیا تھا، تو وہی کوڈ دوبارہ درج
کرنے سے آپ دوبارہ شامل نہیں ہوں گے - اس کے بجائے اپنے استاد سے بحال کرنے کی
درخواست کریں۔
