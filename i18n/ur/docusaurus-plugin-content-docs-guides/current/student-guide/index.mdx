# طلبہ کی رہنمائی

یہ رہنما بتاتا ہے کہ بی ایڈ میگا ٹیکسٹ بک پلیٹ فارم کو ایک طالب علم کے طور پر
کیسے استعمال کیا جائے — سائٹ پر رستہ تلاش کرنے سے لے کر، کلاس میں شامل ہونے،
کام جمع کرانے، اپنے گریڈز پڑھنے، اور اپنے ذاتی ڈیش بورڈ کے استعمال تک۔

- [پلیٹ فارم پر تشریف لے جائیں](./navigate-the-platform)
- [کلاس میں شامل ہوں](./join-a-class)
- [کام جمع کرائیں](./submit-work)
- [اپنے گریڈز پڑھیں](./read-grades)
- [ڈیش بورڈ استعمال کریں](./use-the-dashboard)

اگر اس رہنما میں کچھ اسکرین پر نظر آنے والی چیز سے مماثل نہیں تو ایپ خود ہی
درست معلومات کا ذریعہ ہے — یہ رہنما مطلوبہ رویہ بیان کرتا ہے، انٹرفیس کی ہر
تفصیل نہیں۔
