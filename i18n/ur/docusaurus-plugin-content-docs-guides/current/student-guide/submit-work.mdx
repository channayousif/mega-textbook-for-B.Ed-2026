# کام جمع کرائیں

جب کوئی استاد اسائنمنٹ شائع کرتا ہے، تو یہ آپ کی کلاس کی اسائنمنٹس فہرست اور
آپ کے ڈیش بورڈ کے اسائنمنٹس ایریا میں ظاہر ہوتی ہے۔

- اسائنمنٹ کھولیں اور متن اور/یا فائل (10 MB تک، اجازت یافتہ فارمیٹ میں)
  منسلک کریں۔
- آپ **آخری تاریخ سے پہلے** کسی بھی وقت اپنا کام دوبارہ ترمیم اور جمع کرا
  سکتے ہیں — دوبارہ جمع کرانا آپ کے پچھلے جواب کی جگہ لے لیتا ہے، پرانے
  ورژن محفوظ نہیں رکھے جاتے۔
- آخری تاریخ کے بعد، آپ کی جمع کرائی گئی چیز مقفل ہو جاتی ہے۔ آیا تاخیر سے
  جمع کرانا اب بھی قبول ہے یہ اس مخصوص اسائنمنٹ پر منحصر ہے — اسائنمنٹ کا
  صفحہ اور آپ کے ڈیش بورڈ کا اسائنمنٹس ایریا دونوں یہ واضح طور پر بتاتے ہیں۔
- **مشقی کوئز** مختلف طریقے سے کام کرتے ہیں: آپ آخری تاریخ سے پہلے جتنی بار
  چاہیں دوبارہ کوشش کر سکتے ہیں، اور آپ کا بہترین اسکور ہی شمار ہوتا ہے۔
  کوئز آخری تاریخ کے بعد کبھی بھی کوشش قبول نہیں کرتے۔

جیسے ہی آپ کا کام چیک ہوتا ہے، نتیجہ آپ کے گریڈز ایریا اور آپ کے ڈیش بورڈ کے
ہوم پیش منظر میں ظاہر ہوتا ہے — کسی الگ قدم کی ضرورت نہیں۔
