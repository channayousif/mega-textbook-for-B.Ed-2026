# اساتذہ کی رہنمائی

یہ رہنما بتاتا ہے کہ بی ایڈ میگا ٹیکسٹ بک پلیٹ فارم کو ایک استاد کے طور پر
کیسے استعمال کیا جائے - کلاسز اور اسائنمنٹس کے انتظام سے لے کر، گریڈنگ، اپنے
ٹیچر ڈیش بورڈ کے استعمال، کتاب پر رائے دینے اور بہتری تجویز کرنے، اور تصدیق
شدہ استاد بننے سے کیا کچھ کھلتا ہے۔

- [کلاسز اور اسائنمنٹس کا انتظام کریں](./manage-classes-and-assignments)
- [جمع کرائے گئے کام کو گریڈ کریں](./grade-submissions)
- [ٹیچر ڈیش بورڈ استعمال کریں](./use-the-teacher-dashboard)
- [رائے دیں اور بہتری تجویز کریں](./give-feedback-and-suggest-improvements)
- [تصدیق شدہ استاد کا مواد](./verified-teacher-material)

اگر اس رہنما میں کچھ اسکرین پر نظر آنے والی چیز سے مماثل نہیں تو ایپ خود ہی
درست معلومات کا ذریعہ ہے - یہ رہنما مطلوبہ رویہ بیان کرتا ہے، انٹرفیس کی ہر
تفصیل نہیں۔
