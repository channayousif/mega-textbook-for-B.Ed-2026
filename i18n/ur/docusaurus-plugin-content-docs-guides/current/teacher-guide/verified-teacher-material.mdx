# تصدیق شدہ استاد کا مواد

ہر استاد کلاسز بنا سکتا ہے، کام تفویض کر سکتا ہے، اور گریڈ کر سکتا ہے - یہ
`teacher` کردار خود ہی ہے، اور اسے کسی خاص منظوری کی ضرورت نہیں۔ ایک الگ
صلاحیت، **تصدیق شدہ استاد**، محدود مواد تک رسائی کھولتی ہے:

- کسی تشکیلی یا تخلیصی یونٹ آئٹم کی سرکاری جوابی کلید یا مارکنگ روبرک، جو
  براہ راست گریڈنگ قطار میں دکھائی جاتی ہے۔
- پریکٹس کوئزز کے پیچھے درست جواب کا ڈیٹا (کوئز کے سوالات خود سب کو نظر آتے
  ہیں؛ صرف جوابی کلید محدود ہے)۔

تصدیق شدہ استاد کا درجہ صرف ایک ایڈمن کی طرف سے دیا جاتا ہے - یہ کوئی ایسی
چیز نہیں جسے آپ خود اپنے لیے فعال کر سکیں، اور یہ آپ کے اکاؤنٹ یا آپ کی
کلاسز کے بارے میں کچھ اور تبدیل نہیں کرتا۔ اگر آپ سمجھتے ہیں کہ آپ کو یہ
صلاحیت حاصل ہونی چاہیے اور نہیں ہے، تو اپنے پلیٹ فارم ایڈمنسٹریٹر سے رابطہ
کریں۔
