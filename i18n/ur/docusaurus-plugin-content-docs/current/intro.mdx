# میگا ٹیکسٹ بک

یہ ایک عوامی، دو لسانی (انگریزی + اردو) نصابی کتابوں کا مجموعہ اور سیکھنے کا پلیٹ فارم ہے۔
MVP سندھ حکومت کے تحت **ADE اور B.Ed(H) طلباء اور ان کے اساتذہ** اور **STEDA
تیچنگ لاسنس کے متمنیوں** کی خدمت کرتا ہے۔ گریڈ 9-12 مضامین اگلی منصوبہ بندی میں ہیں۔

سائیڈبار سے **سمسٹر → کورس → یونٹ** دیکھیں، ٹاپ بار میں اردو / انگریزی ٹوگل سے
زبان بدلیں، اور پوری کتاب تلاش کریں۔

> مواد پہلے سمسٹر 1–4 تک لکھا جاتا ہے؛ تمام 8 سمسٹر کا ڈھانچہ موجود ہے، اور
> لکھے نہ گئے یونٹوں کو **جلد آ رہا ہے** کا نشان لگایا جاتا ہے۔
