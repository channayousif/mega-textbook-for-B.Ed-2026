# جامع تشخیص

## اختتامِ یونٹ سوال

اپنے استاد کی فراہم کردہ جماعتی اخلاقی مخمصے کا منظرنامہ پڑھیں۔ ہمدردی–سیاق و سباق–غور و
فکر–عمل فریم ورک کا استعمال کرتے ہوئے اس پر عمل کریں:

- **ہمدردی**: اس صورتحال سے کون متاثر ہوتا ہے، اور کیسے؟
- **سیاق و سباق**: فیصلہ کرنے سے پہلے آپ کو کن مخصوص حقائق کی ضرورت ہوگی — اور آپ کو کس چیز کو
  مفروضہ سمجھنے سے گریز کرنا چاہیے؟
- **غور و فکر**: اپنی ذمہ داریوں کے مقابلے میں کم از کم دو ممکنہ ردعمل کو تولیں۔
- **عمل**: وہ ردعمل بیان کریں جو آپ اپنائیں گے، اور اسے اوپر کے غور و فکر کی بنیاد پر درست
  ثابت کریں، منظرنامے کو دہرانے کی بجائے۔
