# تشکیلی تشخیص

## فوری جانچ

1. ابتدائی تربیت مکمل کرنے کے بعد پیشہ ورانہ ترقی کیوں جاری رہتی ہے؟
2. اس یونٹ میں بیان کردہ پیشہ ورانہ ترقی کے تین مراحل کا نام بتائیں۔
3. پیشہ ورانہ تعلمی برادری کیا ہے؟
4. اس یونٹ میں بیان کردہ دو غور و فکر پر مبنی آلات کا نام بتائیں۔
5. ذاتی ترقیاتی منصوبے کو دراصل عمل میں لانے کے امکانات زیادہ کیا بناتا ہے؟
6. اس یونٹ سے رسمی پیشہ ورانہ ترقیاتی سرگرمی کی ایک مثال دیں۔
