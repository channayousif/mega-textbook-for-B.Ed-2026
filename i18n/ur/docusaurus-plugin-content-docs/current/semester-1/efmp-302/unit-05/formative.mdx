# تشکیلی تشخیص

## فوری جانچ

1. اس یونٹ میں بیان کردہ تدریسی پیشے کے تین روزمرہ چیلنجز بتائیں۔
2. کثیر درجاتی کلاس روم کو واحد درجے سے زیادہ مشکل کیا بناتا ہے؟
3. اساتذہ کے لیے ڈیجیٹل دور کی پیشہ واریت کی توقع کی ایک مثال دیں۔
4. اس یونٹ کا "نشوونما کے ساتھ چیلنجز کا جواب دینا، صرف برداشت کے ساتھ نہیں" سے کیا مطلب ہے؟
5. اگر مدد اور وسائل ساتھ ساتھ نہ بڑھیں تو جوابدہی کی بڑھتی ہوئی توقعات ایک چیلنج کیوں ہو سکتی
   ہیں؟
