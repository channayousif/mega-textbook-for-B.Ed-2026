# تشکیلی تشخیص

## فوری جانچ

1. اس یونٹ میں مؤثر اساتذہ سے منسلک تین ذاتی خوبیاں بتائیں۔
2. صرف امتحانی کارکردگی تدریسی افادیت کا مکمل پیمانہ کیوں نہیں ہے؟
3. کلاس روم میں زبانی اور غیر زبانی ابلاغ کی ایک ایک مثال دیں۔
4. استاد کے صرف معلومات پہنچانے کی بجائے "سہولت کار" کے طور پر عمل کرنے کا کیا مطلب ہے؟
5. ایک مؤثر استاد کسی ساتھی کے ساتھ اختلاف کو کیسے سنبھال سکتا ہے، اس کی ایک مثال بیان کریں۔
6. اس یونٹ میں بیان کردہ استاد کے پانچ بدلتے ہوئے کرداروں میں سے دو کا نام بتائیں۔
