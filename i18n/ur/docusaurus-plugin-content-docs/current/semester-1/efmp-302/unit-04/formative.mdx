# تشکیلی تشخیص

## فوری جانچ

1. ایک جملے میں بتائیں کہ پیشہ ورانہ معیار کیا ہے؟
2. پیشہ ورانہ معیارات کیوں موجود ہیں، بجائے اس کے کہ معیار ہر اسکول کے اپنے فیصلے پر چھوڑ دیا
   جائے؟
3. پاکستان کے اساتذہ کے لیے قومی پیشہ ورانہ معیارات کیسے منظم ہیں - ڈومینز اور اشارے کیا ہیں؟
4. بیان کریں کہ ایک استاد ایماندارانہ خود تشخیص کے لیے ایک ڈومین کیسے استعمال کر سکتا ہے۔
5. خود تجزیے سے آگے پیشہ ورانہ معیارات عام طور پر کن دو چیزوں سے جڑتے ہیں، بتائیں۔
6. یہ کیوں اہم ہو سکتا ہے کہ لائسنسنگ اور تشخیص کارکردگی وہی معیارات استعمال کریں جو ایک استاد
   پہلے سے روزمرہ استعمال کرتا ہے؟
