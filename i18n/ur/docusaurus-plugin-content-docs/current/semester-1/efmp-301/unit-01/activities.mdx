# سرگرمیاں

## سرگرمی 1: سیکھنے کی نشاندہی

جوڑوں میں کسی حالیہ سبق کو بیان کریں اور ایک ایسا لمحہ پہچانیں جہاں حقیقی سیکھنا ہوا۔ بتائیں استاد نے کیا کیا جو مددگار ثابت ہوا۔

## سرگرمی 2: ایک چھوٹی تبدیلی کی منصوبہ بندی

یونٹ سے کوئی ایک تصور منتخب کریں اور ایک ایسی تبدیلی بیان کریں جو آپ کسی سبق میں کریں گے تاکہ طلبہ بہتر سیکھ سکیں۔
