# نگرانی، جائزہ اور چیلنجز

پالیسیاں اور منصوبے خود بخود نافذ نہیں ہوتے۔ اسلام آباد میں پالیسی کے اعلان سے لے کر ضلع کے کسی اسکول کی جماعت میں تبدیلی آنے تک، فیصلوں، وسائل اور اقدامات کی ایک کڑی برقرار رہنا ضروری ہے۔ یہ کڑی ٹوٹ جائے تو پالیسی ناکام ہو جاتی ہے۔ یہ یونٹ اس کڑی کے دو پہلو دیکھتا ہے۔ پہلا یہ کہ ہم کیسے معلوم کریں کہ پالیسی حسبِ ارادہ نافذ ہو رہی ہے، اور کیسے پرکھیں کہ وہ کارگر ہے؟ دوسرا یہ کہ پاکستان کے حالات میں کون سی قوتیں اس کڑی کو سب سے زیادہ توڑتی ہیں؟

## یونٹ کے تعلیمی نتائج

اس یونٹ کے اختتام تک آپ اس قابل ہوں گے کہ:

1. تعلیم میں نگرانی اور جائزہ کا مفہوم بیان کر سکیں اور دونوں میں فرق کر سکیں۔
2. نگرانی اور جائزہ کا عمل بیان کر سکیں اور ہر مرحلے کے لیے مناسب آلات کی شناخت کر سکیں۔
3. پاکستان میں پالیسی کے نفاذ کو روکنے والے بڑے چیلنجز، یعنی مالی، سیاسی اور بیوکریٹک چیلنجز، کی شناخت کر سکیں۔
4. کسی بیان کردہ واقعے میں تجزیہ کر سکیں کہ یہ چیلنجز مل کر نفاذ کی ناکامی کیسے پیدا کرتے ہیں۔

## پیشگی معلومات

یونٹ 3 میں منصوبہ بندی کا عمل متعارف ہوا تھا: ضروریات کا تعین، اہداف مقرر کرنا، وسائل مختص کرنا اور نفاذ۔ یہ یونٹ اسی مقام سے آگے بڑھتا ہے جہاں وہ عمل ختم ہوتا ہے۔ نگرانی اور جائزہ وہ مراحل ہیں جو بتاتے ہیں کہ منصوبہ کارگر ہے یا نہیں۔ اس یونٹ کو شروع کرنے سے پہلے آپ کو یہ بات واضح ہونی چاہیے کہ منصوبہ بندی مرحلہ وار عمل ہے جس کا آغاز، درمیانی حصہ اور اختتام ہوتا ہے۔
