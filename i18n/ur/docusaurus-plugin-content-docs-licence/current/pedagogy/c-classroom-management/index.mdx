# C. کلاس روم مینجمنٹ

کلاس روم مینجمنٹ حصہ دوم کا وہ واحد عنوان ہے جس کے لیے 2026 کے بی ایڈ نصاب میں کوئی کورس نہیں، اس لیے اس کا زیادہ تر حصہ یہیں پوری طرح پڑھایا گیا ہے۔ اس میں ماحول، معمولات، مشترکہ اقدار اور وہ حکمتِ عملیاں شامل ہیں جو سیکھنے کو ممکن بناتی ہیں۔

## نصاب کے مقاصد

نیچے ہر سطر حصہ دوم کا ایک مقصد ہے، لائسنس نصاب سے لفظ بہ لفظ۔ اس کا صفحہ بتاتا ہے کہ ٹیسٹ
کیا پوچھتا ہے، جہاں ڈگری کا کوئی موضوع اسے پہلے سے پڑھاتا ہے وہاں اس کا ربط دیتا ہے، جو
ڈگری چھوڑ دیتی ہے اسے شامل کرتا ہے، اور تعمیری جواب والی مشق پر ختم ہوتا ہے۔
