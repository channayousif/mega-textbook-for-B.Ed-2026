# /sp.clarify - Clarify Ambiguous Requirements

## When to Use

When user intent is unclear or requirements are ambiguous.

## Process

1. Read the relevant spec: `specs/{{FEATURE_DIR}}/spec.md`
2. Read the constitution: `.specify/memory/constitution.md`
3. Identify the ambiguity
4. Ask 2-3 targeted clarifying questions
5. Record decisions in the spec or plan

## Output

- Clarifying questions presented to user
- Answers recorded in appropriate spec/plan sections
