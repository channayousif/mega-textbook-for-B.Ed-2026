# /sp.checklist - Create Checklist

## When to Use

When user requests a checklist for a feature or task.

## Process

1. Read the relevant spec/plan/tasks
2. Identify checklist items from requirements
3. Organize by category
4. Number items sequentially

## Output

- Checklist written to `specs/{{FEATURE_DIR}}/checklist.md`
- Format: `[CHK001] Description`
