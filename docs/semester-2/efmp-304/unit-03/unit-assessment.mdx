## Unit summary

This unit turned Unit 2's skill of finding an argument into the skill of judging it. The single idea
running through all four topics is this: **an argument promises either a guarantee or a probability,
and the test you apply must match the promise.**

- **Topic 3.1** gave the distinction: a deductive argument claims its premises guarantee the
  conclusion; an inductive argument claims they make it probable. The test for the first is
  validity; the test for the second is strength.
- **Topic 3.2** named the four common deductive patterns: the categorical syllogism, modus ponens,
  modus tollens and the chain argument. Each has a near-miss fallacy that looks like it but does not
  follow.
- **Topic 3.3** named the four common inductive patterns: generalisation, analogy, causal inference
  and prediction. Each has a characteristic way of getting stronger and a characteristic way of
  getting weaker.
- **Topic 3.4** put the four terms into a grid: validity and soundness for deductive arguments,
  strength and cogency for inductive ones. The most common error is to judge one kind by the other
  kind's test.

Three habits should survive this unit. First, classify before you judge, because an argument that
promises a guarantee and an argument that promises probability are tested in different ways.
Second, validity is about the link between premises and conclusion, not about whether the premises
are true. Third, a strong inductive argument is not a failed deductive one; it is a different kind
of thing, and it is the kind you will meet most often in school life.

## Summative assessment

### Multiple-choice questions (MCQs)

Choose the single best answer for each question.

1. *(Remember)* A deductive argument claims that its premises, if true,:
   - A) Make the conclusion probable
   - B) Guarantee the conclusion
   - C) Are probably true
   - D) Are more important than the conclusion

2. *(Understand)* Which question reliably separates a deductive argument from an inductive one?
   - A) Does the argument contain numbers?
   - B) Does the argument come from an official source?
   - C) Do the premises claim to guarantee the conclusion, or only to make it probable?
   - D) Is the conclusion one most teachers would accept?

3. *(Apply)* "All teachers who have used their casual leave are refused further leave. Mr Hussain
   has used his. So he is refused." This argument is best classified as:
   - A) Inductive, because it is about a teacher
   - B) Deductive, because the premises claim to guarantee the conclusion
   - C) Inductive, because the conclusion might be wrong
   - D) Deductive, because it is a short argument

4. *(Remember)* The test that applies to a deductive argument is:
   - A) Strength
   - B) Cogency
   - C) Validity
   - D) Probability

5. *(Apply)* "The last three cohorts that had a practical orientation week scored higher. So this
   cohort should have one." This argument is best classified as:
   - A) Deductive, because it reaches a recommendation
   - B) Inductive, because the premises make the conclusion probable but do not guarantee it
   - C) Deductive, because it uses evidence
   - D) Inductive, because it is about a school

6. *(Understand)* A valid deductive argument with a false premise is:
   - A) Sound
   - B) Invalid
   - C) Valid but unsound
   - D) Cogent

7. *(Apply)* "If a teacher has an emergency, he is granted leave. Mr Hussain was not granted leave.
   So he has no emergency." This argument uses the pattern called:
   - A) Affirming the consequent
   - B) Denying the antecedent
   - C) Modus tollens
   - D) A hasty generalisation

8. *(Remember)* An inductive argument that is strong and has true premises is called:
   - A) Valid
   - B) Sound
   - C) Cogent
   - D) Deductive

9. *(Understand)* "Valid means true" is a mistake because:
   - A) Validity is about the link between premises and conclusion, not about whether the premises are true
   - B) Validity is only about inductive arguments
   - C) True arguments are never valid
   - D) Validity requires the conclusion to be false

10. *(Apply)* "Every class I have taught has had at least one non-reader. So my new grade 6 will
    have one." This argument's strength depends most on:
    - A) Whether the conclusion is guaranteed
    - B) How many classes and how varied they were
    - C) Whether the argument is valid
    - D) Whether the teacher is certain

### Restricted-response questions (RRQs)

1. *(Understand)* In two sentences, state the difference between a deductive argument and an inductive argument. Do not use the word "logic" in your answer.

2. *(Understand)* Explain in two or three sentences why a valid deductive argument is not necessarily sound. Use a school example.

3. *(Apply)* Classify this argument as deductive or inductive and say whether it is valid or strong: "All pupils who miss more than ten days are flagged. Sara missed twelve days. So Sara is flagged."

4. *(Understand)* A trainee says, "A strong inductive argument is just a deductive argument that is not quite certain." Give two reasons that is wrong.

5. *(Analyze)* "If the grant arrives, the laboratory is repaired. The laboratory was not repaired. So the grant did not arrive." Name the pattern, say whether it is valid, and say what would have to be true for it to be sound.

6. *(Understand)* For each of the four inductive patterns in Topic 3.3, state in one clause what makes it stronger. List all four.

7. *(Analyze)* "Three of the four schools in our union council that added a Saturday class saw results improve. So we probably will too." Name the pattern, say whether it is strong or weak as stated, and name the premise that is doing most of the work.

8. *(Apply)* Give two differences between validity and soundness, using the grid from Topic 3.4.

9. *(Analyze)* A teacher argues: "If a pupil revises, he passes. He did not revise. So he did not pass." Name the pattern, say whether it is valid, and name the fallacy if it is not.

10. *(Analyze)* Classify each of the following as deductive or inductive, with a reason of no more than one clause each: (a) "All schools that submitted on time received the grant. We submitted on time. So we received the grant." (b) "The last five pupils who attended regularly all passed. Ahmed attends regularly. So he will probably pass." (c) "If the examination is postponed, the results are delayed. The examination was postponed. So the results are delayed." (d) "Every class I taught last year did well. So the class I am teaching this year will do well."

### Extended-response questions (ERQs)

1. *(Analyze)* Here is a staffroom argument:

    > "All teachers who arrive after the first bell are marked late. Mr Soomro was marked late. So
    > he arrived after the first bell."

    In 150 to 200 words, name the pattern, say whether it is valid, name the fallacy if it is not, and
    say what the arguer would have to change to make it valid.

2. *(Evaluate)* A head teacher argues: "Every school that introduced a morning reading period saw
    their language scores improve within two years. So if we introduce one, our scores will improve."
    In 200 to 250 words, classify the argument, say whether it is strong or weak as stated, name the
    specific premise the argument leans on, and say what evidence would most strengthen it.

3. *(Evaluate)* Two teachers argue about whether to change the examination schedule:

    > **A.** "All schools that set their examination before the board date get their results earlier.
    > We are setting ours before the board date. So we will get our results earlier."
    >
    > **B.** "The three schools in our union council that set their examination before the board date
    > all got their results earlier. So we probably will too."

    In 200 to 250 words, classify each argument, judge each by its own test, say which gives the
    better basis for the decision, and justify your judgement from the arguments' own wording.

4. *(Analyze)* Take this staffroom notice:

    > "If the grant arrives by March, the science laboratory will be repaired. If the laboratory is
    > repaired, grade 9 can do practicals. The grant arrived in February. So grade 9 can do
    > practicals."

    In 200 to 250 words, name the pattern or patterns in this argument, say whether it is valid as
    stated, and say what would have to be checked to decide whether it is sound.

5. *(Create)* **Integrative.** Choose one real argument you have heard in a staff meeting, a
    conversation or a document this week. In 250 to 300 words, produce a full analysis that (a)
    classifies it as deductive or inductive, (b) names the pattern, (c) judges it by the right test,
    (d) says whether it is sound or cogent, and (e) says what would go wrong if you judged it by the
    wrong test. If the argument is neither deductive nor inductive (an explanation, an assertion, a
    description), say so and defend that finding, which is a complete answer rather than a failed
    one.

## Answers and marking guidance

This section is for self-study. Work each question before reading it.

### MCQ answer key

1. B - a deductive argument claims the premises guarantee the conclusion; A describes an inductive argument.
2. C - the distinction turns on whether the premises claim a guarantee or only probability.
3. B - if the premises are true, the conclusion cannot be false; that is the definition of a deductive argument.
4. C - validity is the test for deductive arguments; strength is the test for inductive ones.
5. B - the premises make the conclusion probable but do not guarantee it; that is the definition of an inductive argument.
6. C - a valid argument with a false premise is valid but unsound; soundness requires true premises.
7. C - if P then Q; Q is false; so P is false; this is modus tollens.
8. C - a strong inductive argument with true premises is cogent; sound is the deductive parallel.
9. A - validity is about the link, not about the truth of the premises; an argument can be valid with false premises.
10. B - the strength of a generalisation depends on the number and variety of cases; the argument does not claim a guarantee.

### RRQ model answers and mark schemes

1. Model: a deductive argument claims its premises guarantee the conclusion; an inductive argument claims its premises make the conclusion probable but do not guarantee it. **Marks (3):** 1 - states the guarantee claim; 1 - states the probability claim; 1 - the two are contrasted.

2. Model: validity is about whether the conclusion follows from the premises; soundness is about whether it follows from true premises. Example: "All teachers are head teachers. Mr Soomro is a teacher. So he is a head teacher" is valid but unsound because the first premise is false. **Marks (3):** 1 - defines validity as the link; 1 - defines soundness as the link plus true premises; 1 - a school example that fits.

3. Model: deductive. The premises claim to guarantee the conclusion. It is valid: if both premises are true, the conclusion follows. **Marks (3):** 1 - correctly classified as deductive; 1 - correctly judged valid; 1 - a reason tied to the structure.

4. Model: a strong inductive argument is not a failed deductive argument; it makes a different claim (probability, not guarantee) and is judged by a different test (strength, not validity). Calling it "not quite certainty" treats the deductive standard as the only standard. **Marks (4):** 1 - says it makes a different claim; 1 - says it is judged by a different test; 1 - says the two are not a ranking; 1 - names the error in the trainee's statement.

5. Model: modus tollens. It is valid: if the conditional holds and the outcome did not happen, the condition was not met. For it to be sound, the conditional premise must be true: the grant must be the only way the laboratory can be repaired. **Marks (4):** 1 - names the pattern; 1 - says it is valid; 1 - says what would have to be true for soundness; 1 - ties the soundness condition to the specific premise.

6. Model: generalisation is stronger with more and more varied cases; analogy is stronger with more relevant similarities and fewer relevant differences; causal inference is stronger when alternative causes are ruled out; prediction is stronger with a longer, more stable trend. **Marks (4):** 1 per pattern correctly characterised.

7. Model: generalisation (with a causal claim). It is weak as stated because three schools is a small sample and the argument leans on the unstated premise that nothing else relevant differed between the schools that added the class and those that did not. **Marks (3):** 1 - names the pattern; 1 - says it is weak; 1 - names the unstated premise doing the work.

8. Model: validity is about the link between premises and conclusion; soundness is about the link plus the truth of the premises. An argument can be valid but unsound; an argument cannot be sound but invalid. **Marks (3):** 1 - defines validity; 1 - defines soundness; 1 - states the relationship.

9. Model: denying the antecedent. It is invalid. The fallacy is denying the antecedent: "if P then Q; P is false; so Q is false" does not follow. Q might be true for other reasons. **Marks (3):** 1 - names the pattern; 1 - says it is invalid; 1 - names the fallacy.

10. Model: (a) deductive, premises claim a guarantee; (b) inductive, premises make the conclusion probable; (c) deductive, if-then with the condition met; (d) inductive, generalisation from one year. **Marks (4):** 1 per item, awarded only when the reason matches the label.

### ERQ rubrics

1. Analytic rubric - *Pattern naming* (0-2: correct pattern named / a near-miss / wrong) · *Validity judgement* (0-2: correct with a reason tied to the structure / a general reason / wrong) · *Fallacy naming* (0-2: correct fallacy named / a near-miss / none) · *What would make it valid* (0-2: names a specific change to the argument / a general suggestion / none) · *Clarity* (0-2).

2. Analytic rubric - *Classification* (0-2: correct with a reason / a general reason / wrong) · *Strength judgement* (0-2: strong or weak with a reason / a general reason / wrong) · *The premise it leans on* (0-2: names a specific unstated premise / a general premise / none) · *Strengthening evidence* (0-2: names evidence that genuinely bears on the weakness / something merely interesting / none) · *Clarity* (0-2).

3. Analytic rubric - *Classification* (0-2: both correctly classified / one correct / neither) · *Judgement by the right test* (0-2: each judged by its own test / one correct / neither) · *Which is the better basis* (0-3: a verdict given and justified by named features of each argument (**Evaluate**: the comparison turns on the actual content, not on which conclusion the writer prefers) / a verdict with general reasons / a verdict asserted) · *Clarity* (0-2).

4. Analytic rubric - *Pattern naming* (0-2: chain argument correctly identified / a near-miss / wrong) · *Validity judgement* (0-2: valid with a reason / a general reason / wrong) · *Soundness reasoning* (0-3: says what would have to be checked to decide soundness, tied to the specific premises (**Analyze**: the reasoning turns on the actual content, not on general plausibility) / a general statement / none) · *Clarity* (0-2).

5. Analytic rubric - *Classification* (0-2: correct with a reason / a general reason / wrong, or a defended finding that it is not an argument) · *Pattern naming* (0-2: correct pattern / a near-miss / wrong) · *Judgement by the right test* (0-2: judged by the right test with a reason / a general reason / wrong) · *Soundness or cogency* (0-2: correct with a reason / a general reason / wrong) · *The wrong-test error* (0-2: names a specific error / a general error / none) · *Clarity* (0-2).
