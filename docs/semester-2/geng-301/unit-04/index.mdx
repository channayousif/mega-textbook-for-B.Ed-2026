# Types of Expository Writing

Expository writing is not one thing. Depending on your purpose, you may need to describe a scene,
classify a set of ideas, explain a cause, walk through a procedure or compare two things. This unit
introduces six common expository types and gives you practice in identifying and using each one.

## Unit learning outcomes

By the end of this unit you will be able to:

1. Name and define six expository types: description, illustration, classification, cause and effect,
   process analysis and comparative analysis.
2. Identify which expository type a sample text uses and explain your reasoning.
3. Choose the appropriate expository type for a given writing purpose.
4. Produce a short piece of writing using a specified expository type.

## Prerequisite knowledge

Units 1-3 of this course (GENG-301). You should understand expository writing, the writing process and
essay structure.

## In this unit

1. [Showing and exemplifying](./topic-01) - description and illustration.
2. [Sorting and connecting](./topic-02) - classification and cause/effect.
3. [Explaining steps and comparing](./topic-03) - process analysis and comparative analysis.

## How to use this unit

Each topic covers two expository types. The activities ask you to identify types in sample texts and
produce short examples yourself. The unit assessment tests both recognition and production.
