# Unit 4 Teacher Notes

These notes support the teaching of GENG-301 Unit 4.

## Teaching strategies

This unit teaches six expository types. The most effective approach is recognition then production.

1. **Start each type with recognition.** Give sample paragraphs and ask: "What type is this? How do
   you know?" Recognition before production builds the concept.
2. **Use question-answer** for classification. Give mixed sets of items and ask pupils to sort them.
   Ask: "What principle did you use? Is it consistent?"
3. **Use think-pair-share** for cause and effect. Ask pupils to identify cause-effect relationships in
   their own school experience, then discuss: is this causation or correlation?
4. **Use group work** for process analysis. Have groups write a process analysis for a familiar task
   (making tea, preparing a lesson plan), then evaluate each other's for completeness and order.

## Sequencing

Teach the three topics in order. A reasonable split for a three-week unit:

- Week 1: Topic 4.1 (description and illustration).
- Week 2: Topic 4.2 (classification and cause/effect).
- Week 3: Topic 4.3 (process and comparison) and the unit assessment.

## Likely misconceptions and how to handle them

| Misconception | Topic | How to handle |
|---|---|---|
| "Description means using lots of adjectives" | 4.1 | Compare "a big, beautiful school" with a paragraph that uses specific detail without adjectives. Ask which paints a picture. |
| "Classification can use any categories" | 4.2 | Give a mixed classification (schools by type AND level in the same paragraph). Ask pupils to identify the confusion. |
| "If B happened after A, A caused B" | 4.2 | Give a humorous example: "I wore red socks and won the match, so red socks cause wins." Pupils see the correlation-causation problem. |
| "A comparison must be balanced" | 4.3 | Explain that purpose determines the balance. A comparison arguing for one option emphasizes differences. |

## Practical work

- **Group work**: the classification activity (Topic 4.2) works well in small groups.
- **Group assignment**: as a group, identify the expository types in three different textbook passages
   and present findings to the class.
- **Individual assignment**: each pupil writes one paragraph using each of the six types on a single
   self-chosen topic (six short paragraphs). Submit with a label for each.
- **Presentations**: pairs present their process analysis (Topic 4.3) and explain their step order.
