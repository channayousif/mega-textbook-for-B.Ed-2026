## Unit summary

This unit introduced six expository types.

- Topic 4.1 covered description (sensory detail) and illustration (concrete examples).
- Topic 4.2 covered classification (sorting by a single principle) and cause and effect (causal links).
- Topic 4.3 covered process analysis (step by step) and comparative analysis (block and point-by-point).

Together these give you a toolkit: when a writing task asks you to explain, you can choose the type that
fits your purpose.

## Summative assessment

### Multiple-choice questions (MCQs)

Choose the single best answer for each question.

1. *(Remember)* How many expository types did this unit introduce?
   - A) Four
   - B) Five
   - C) Six
   - D) Seven

2. *(Remember)* Which expository type explains a step-by-step procedure?
   - A) Classification
   - B) Cause and effect
   - C) Process analysis
   - D) Illustration

3. *(Understand)* A paragraph describes "the cracked plaster, the single worn blackboard and the
   thirty-six desks for sixty pupils." Which expository type is this?
   - A) Illustration
   - B) Description
   - C) Classification
   - D) Process analysis

4. *(Understand)* A writer classifies schools by management type (government, private, community) and
   then by level (primary, secondary) in the same paragraph. What is the problem?
   - A) Too many examples
   - B) Two organizing principles mixed in one classification
   - C) No examples given
   - D) The categories are wrong

5. *(Apply)* A pupil wants to explain why absenteeism rises during harvest season. Which expository
   type fits best?
   - A) Description
   - B) Cause and effect
   - C) Classification
   - D) Comparative analysis

6. *(Apply)* A pupil writes: "For example, many schools lack libraries." This is an example of:
   - A) Description
   - B) Illustration
   - C) Process analysis
   - D) Classification

7. *(Apply)* Which comparison structure discusses one point across both subjects before moving to the
   next point?
   - A) Block structure
   - B) Point-by-point structure
   - C) Cause and effect
   - D) Process analysis

8. *(Apply)* A process analysis paragraph jumps from step 1 to step 4. What is missing?
   - A) A goal statement
   - B) Steps 2 and 3
   - C) A conclusion
   - D) An example

9. *(Apply)* A writer says "Test scores dropped the week it rained, so rain caused lower scores." What
   is the reasoning error?
   - A) Correlation mistaken for causation
   - B) Too many examples
   - C) No classification principle
   - D) Missing process steps

10. *(Apply)* A paragraph compares government and private schools point by point on cost, class size
    and facilities. What structure is this?
    - A) Block
    - B) Point-by-point
    - C) Process
    - D) Cause and effect

### Restricted-response questions (RRQs)

Answer each question in the space indicated.

1. *(Understand)* In two sentences, explain the difference between description and illustration.

2. *(Remember)* State the single most important rule for classification and the single most important
   rule for cause and effect.

3. *(Apply)* A pupil writes: "Our school is very good. It has many facilities." Using what you learned
   about description, rewrite this to show rather than tell (one sentence).

4. *(Apply)* Identify the expository type: "To register for the B.Ed programme, first collect the
   application form from the university office. Next, attach your transcripts and certificates. Then
   submit the completed form before the deadline. Finally, wait for the merit list."

5. *(Apply)* A pupil classifies homework into "written homework, reading homework and thinking
   homework." Is this a valid classification? Explain why or why not in one sentence.

6. *(Understand)* Explain why point-by-point comparison is often clearer than block comparison.

7. *(Apply)* Write one cause-and-effect sentence about a Pakistani school context that names the cause,
   the effect and the mechanism.

8. *(Analyze)* A paragraph describes a school in detail but never makes a point about it. Using what
   you learned, explain what is wrong and what the writer should add.

9. *(Apply)* Write the first two steps of a process analysis for "How to conduct a parent-teacher
   meeting." Include a goal statement.

10. *(Analyze)* A comparison paragraph discusses all points about government schools, then all points
    about private schools, but never directly compares them. Identify the structure, explain its
    weakness and suggest a fix.

### Extended-response questions (ERQs)

Answer each question in a short paragraph (80-140 words unless stated otherwise).

1. *(Analyze)* This unit introduced six expository types. Choose two that are easily confused
   (description and illustration, or classification and comparison) and explain, with examples, how to
   tell them apart.

2. *(Apply)* A B.Ed pupil needs to write an essay on "Why many Grade 5 pupils cannot read fluently."
   Recommend one expository type from this unit and explain why it fits. Then write the opening
   sentence of the essay using that type.

3. *(Analyze)* Read this paragraph and identify the expository type. Then evaluate its effectiveness.
   > "A government primary school in rural Sindh typically has one teacher for three grades, a
   > single room with a tin roof, and no electricity. Pupils sit on jute sacks. The teacher uses a
   > single textbook shared among fifteen pupils."
   Is the type used well? What makes it effective or ineffective?

4. *(Evaluate)* A pupil writes a process analysis for "How to teach a new concept to Grade 3" with
   these steps: (1) Explain the concept, (2) Give homework. Evaluate this process: what is missing?
   What steps should be added between the two?

5. *(Create)* Choose one expository type from this unit and write a short paragraph (60-80 words)
   using it on the topic "The value of homework in primary school." State which type you chose and
   explain in one sentence why it suits the topic.

## Answers and marking guidance

This section is for self-study. Try every question above before you look back at the keys below.

### MCQ answer key

1. **C** - Six: description, illustration, classification, cause/effect, process, comparison.
2. **C** - Process analysis explains step-by-step procedures.
3. **B** - Description: sensory detail (cracked plaster, worn blackboard) paints a picture.
4. **B** - Two organizing principles (management type AND level) mixed in one classification.
5. **B** - Cause and effect: the task asks "why," which requires exploring causal links.
6. **B** - Illustration: "For example" introduces a concrete example supporting a claim.
7. **B** - Point-by-point structure compares one point across both subjects before moving on.
8. **B** - Steps 2 and 3 are missing. A process analysis must include all steps in order.
9. **A** - Correlation mistaken for causation: two things happening together does not prove one caused the other.
10. **B** - Point-by-point: each paragraph compares one point (cost, then class size, then facilities) across both subjects.

### RRQ model answers and mark schemes

1. **Model:** Description uses sensory detail to paint a picture. Illustration uses concrete examples to support a claim. **Marks (2):** 1 per correct distinction.

2. **Model:** Classification: use a single organizing principle. Cause and effect: show a real causal link, not just correlation. **Marks (2):** 1 per correct rule.

3. **Model:** Any specific descriptive sentence. E.g. "Our school has one science lab with six working benches for thirty pupils." **Marks (2):** 1 - specific detail; 1 - shows rather than tells.

4. **Model:** Process analysis. It lists steps in order with a goal (registering for B.Ed). **Marks (1).**

5. **Model:** It depends on the principle. If "type of mental effort" is the principle, it is valid. If the principle is unclear or mixes categories, it is not. **Marks (2):** 1 - evaluates validity; 1 - explains the reasoning.

6. **Model:** Point-by-point lets the reader see the comparison directly at each point. Block comparison makes the reader hold all of A in memory while reading all of B. **Marks (2):** 1 - explains the clarity advantage; 1 - names the reader-memory problem with block.

7. **Model:** Any cause-effect sentence with cause, effect and mechanism. E.g. "When a school provides free textbooks (cause), attendance rises (effect) because families no longer keep children home to share one book among siblings (mechanism)." **Marks (2):** 1 - names cause and effect; 1 - includes mechanism.

8. **Model:** Description without a point is just a list of details. The writer should add a topic sentence that tells the reader what the description proves or shows. **Marks (2):** 1 - identifies the missing point; 1 - suggests adding a topic sentence.

9. **Model:** Goal + two steps in order. E.g. "The goal of a parent-teacher meeting is to share pupil progress and agree on support. First, prepare a one-page summary for each pupil. Next, arrange seating so parents face you, not each other." **Marks (2):** 1 - goal stated; 2 - steps in order.

10. **Model:** Block structure. Weakness: the reader must make the comparisons themselves. Fix: reorganize point by point, comparing each point across both school types. **Marks (2):** 1 - identifies structure and weakness; 1 - suggests point-by-point fix.

### ERQ rubrics

**1. Confusable types**
| Criterion | 0-3 |
|---|---|
| Names both types correctly | 0-1 |
| Explains how to tell them apart | 0-1 |
| Gives a concrete example of each | 0-1 (**Analyze**: examples clearly illustrate the distinction**) |

**2. Type recommendation**
| Criterion | 0-3 |
|---|---|
| Recommends an appropriate type | 0-1 |
| Explains why it fits the topic | 0-1 |
| Opening sentence uses the type correctly | 0-1 |

**3. Type identification and evaluation**
| Criterion | 0-3 |
|---|---|
| Correctly identifies the type (description) | 0-1 |
| Evaluates effectiveness with evidence | 0-1 |
| Evidence is specific to the text | 0-1 (**Analyze**: notes the lack of a point as the weakness**) |

**4. Process evaluation**
| Criterion | 0-3 |
|---|---|
| Identifies what is missing (intermediate steps) | 0-1 |
| Suggests at least two steps to add | 0-1 |
| Steps are in logical order | 0-1 |

**5. Type production**
| Criterion | 0-3 |
|---|---|
| Paragraph uses the stated type correctly | 0-1 |
| Type suits the topic | 0-1 |
| Explanation is specific | 0-1 (**Analyze**: shows why the type fits the purpose**) |
