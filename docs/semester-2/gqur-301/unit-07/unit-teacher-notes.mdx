# Unit 7 teacher notes

These notes are for the instructor delivering GQUR-301 Unit 7, which follows
Chapter 7 of the course guide (Week 7). They complement the student-facing
topics with teaching strategies, likely difficulties and practical work, in
line with the guide's teaching strategy of lectures, discussion,
question-answer, brainstorming and practical group and individual work.

## Sequencing suggestion

| Week | Topic | Focus |
|---|---|---|
| 7 (first session) | 7.1 Basic counting principles | Outcomes; systematic listing; the addition rule; overlapping groups |
| 7 (second session) | 7.2 Multiplicative rule | Staged choices; tree diagrams; deciding to add or multiply |

## Teaching strategies

### Topic 7.1 Basic counting principles

**Opening.** Ask three volunteers to call out uniform combinations from two
shirt colours and two trouser colours while you write them in the order
given. Then ask the class whether the list is complete and has no repeats.
The need for a method appears at once.

**Key move.** Model "fix the first choice, run through the second" on the
board, then give a problem with overlapping groups (two clubs with shared
members). Ask a pupil who is in both clubs to stand up and ask, "How many
times did we count you?"

### Topic 7.2 Multiplicative rule

**Opening.** Pose the Larkana timetable question and take a quick vote:
5 or 6? Then write out the six timetables.

**Key move.** Build the school-lunch tree on the board one stage at a time,
counting end points after each stage, so that students see each stage
multiplying the count. Then give the cricket-or-hockey positions problem,
where the branches are unequal, so that the tree visibly beats a single
multiplication.

## Common misconceptions and how to address them

| Misconception | How to address |
|---|---|
| "You can always count outcomes by listing them" | Ask for a list of all three-digit cupboard-lock codes; after a minute, ask how long the full list would take. |
| "Choices made one after another should be added" | Write out the six timetables; ask students to explain where the sixth one came from that 3 + 2 missed. |
| "A tree diagram is only a drawing, not a method" | Use a tree with unequal branches, where the multiplicative rule alone fails and the tree still counts correctly. |

A good discussion prompt is: "A pupil picks one storybook and one magazine.
Another picks one storybook or one magazine. Why are the two counts
different?" A likely wrong answer is that both are 5 + 3, because both
mention the same books; ask what one complete outcome looks like in each.

## Practical work

1. **List it, then add it (Topic 7.1).** Pairs compare haphazard and systematic lists, then use the addition rule.
2. **Build a timetable tree (Topic 7.2).** Groups of three count timetables by rule, by tree and by list, then reconcile.
3. **Code audit (both topics).** Individual assignment: count how many codes a real school or library numbering format allows and report whether it will run out.

## Assessment guidance

The unit assessment (10 MCQ / 10 RRQ / 5 ERQ) is summative. Use each topic's
"Check your understanding" items for formative assessment during teaching.
The practicum tasks link the college classroom to the placement school.
