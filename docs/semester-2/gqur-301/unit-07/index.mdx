# Counting Techniques

Units 1 to 6 were about describing data that someone had already collected.
This unit, which follows Chapter 7 of the course guide, turns to a different
question: before anything happens, how many different things *could* happen?
How many uniform combinations can a school allow, how many ways can a
timetable be filled, how many different ID codes can a system issue? Counting
the possibilities carefully is the foundation of probability, which starts in
Unit 9.

## Unit learning outcomes

By the end of this unit you will be able to:

1. List the outcomes of a simple choice systematically, so that none is missed and none is repeated.
2. Use the addition rule to count the outcomes of a choice between groups of options that do not overlap, and correct the count when groups do overlap.
3. Use the multiplicative rule and a tree diagram to count the outcomes of choices made one after another, and decide whether a real problem needs adding or multiplying.

## Prerequisite knowledge

HSC-level arithmetic: adding, multiplying and subtracting whole numbers. No
earlier unit is required, although the school examples will feel familiar from
Units 1 and 2.

## In this unit

1. [Basic counting principles](./topic-01) - outcomes, systematic listing and the addition rule.
2. [Multiplicative rule](./topic-02) - counting choices made in stages, with a tree diagram.

## How to use this unit

Each topic is one learning cycle. Start with the classroom situation, work
through the explanation and its worked examples, and try the activity with a
partner before you move on. The "Check your understanding" items help you
retrieve what you have learned: try them without looking back, then check.
The unit ends with a summative assessment that draws both topics together.
