# Data Organization and Presentation

A raw list of figures hides its own pattern. This unit, which follows Chapter 2
of the course guide, gives you the two tools that reveal it: a table that counts
how often each value or interval occurs, and a chart that lets a reader see the
pattern at a glance. Both build directly on the data types from Unit 1, because
the type of data decides which table and which chart make sense.

## Unit learning outcomes

By the end of this unit you will be able to:

1. Construct a frequency distribution table and a cumulative frequency column from a raw data set, and read both.
2. Choose and produce an appropriate graphical representation (bar chart, histogram or pie chart) for a given data set and interpret what it shows.

## Prerequisite knowledge

Unit 1 (data types). You should be able to tell qualitative from quantitative
data and discrete from continuous data.

## In this unit

1. [Tabular presentation of data](./topic-01) - frequency distribution tables and cumulative frequency.
2. [Graphical representation](./topic-02) - bar charts, histograms and pie charts.

## How to use this unit

Each topic is one learning cycle. Start with the classroom situation, work through
the explanation, and try the activity before you move on. The "Check your
understanding" items are there to help you retrieve what you have learned: have
a go at them without looking back, then check your answer. The unit ends with a
summative assessment that draws the two topics together.
