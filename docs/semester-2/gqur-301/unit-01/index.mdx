# Introduction to Data and Data Organization

Every teacher works with data every day, whether they call it that or not. A
list of test marks, a head-count of pupils present, a table of enrolment by
gender, a chart of school budget spending - all of these are data. This unit
begins the course by making that everyday material precise. Before you can
analyze data, you need to know what kind of data it is, where it came from, how
to organize it into a table, and how to display it so that a reader can see the
pattern at a glance.

## Unit learning outcomes

By the end of this unit you will be able to:

1. Distinguish qualitative from quantitative data and discrete from continuous
   data, and classify a given data set by type.
2. Distinguish primary from secondary sources of data and explain when each is
   appropriate.
3. Construct a frequency distribution table and a cumulative frequency table
   from a raw data set.
4. Choose and produce an appropriate graphical representation (bar chart,
   histogram, or pie chart) for a given data set and interpret what it shows.

## Prerequisite knowledge

None beyond HSC-level general study skills and everyday numeracy. This is the
opening unit of GQUR-301. GQUR-300 (Semester 1) is helpful preparation but is not
formally required.

## In this unit

1. [Types of data](./topic-01) - qualitative vs quantitative, discrete vs continuous.
2. [Sources of data](./topic-02) - primary and secondary sources.
3. [Frequency distributions](./topic-03) - frequency tables and cumulative frequency.
4. [Graphical representation](./topic-04) - bar charts, histograms and pie charts.

## How to use this unit

Each topic is one learning cycle. Start with the classroom situation, work through
the explanation, and try the activity before you move on. The "Check your
understanding" items are there to help you retrieve what you have learned - have
a go at them without looking back, then check your answer. The unit ends with a
summative assessment that draws the four topics together.
