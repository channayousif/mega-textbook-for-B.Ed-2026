# B.Ed (4-Year) Mega Textbook

A public, bilingual (English + Urdu) digital textbook for the B.Ed (4-Year) programme.
Use the sidebar to browse **Semester → Course → Unit**, switch language with the اردو /
English toggle in the top bar, and search the whole book.

> Content is authored Semesters 1–4 first; all 8 semesters are scaffolded, and
> un-authored units are marked **coming soon**.
