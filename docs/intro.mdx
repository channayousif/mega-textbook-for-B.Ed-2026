# Mega Textbook

A public, bilingual (English + Urdu) collection of textbooks and a learning platform for **Grades 9-12** and **teacher education (ADE, B.Ed Hons)**. The current release is an MVP for prospective teachers (ADE/B.Ed students) and their teachers; Grade 9-12 subject tracks are next.

Use the sidebar to browse **Semester → Course → Unit**, switch language with the اردو /
English toggle in the top bar, and search the whole book.

> Content is authored Semesters 1–4 first; all 8 semesters are scaffolded, and
> un-authored units are marked **coming soon**.
