## Teaching strategies

The course guide names lectures, class discussion, question-answer sessions and brainstorming, together with group work, assignments and presentations. Use a short explanation to model a reasoning move, then group work to practise it. The following suggestions adapt those guide-named approaches to this unit; they are not additional required guide sections.

Begin Topic 4.1 with the contrast between an attractive poster and an evidence-based proposal. Ask, "What would we need to know before advising the class to change this routine?" A likely response is "Tell pupils to stop littering." Acknowledge the concern, then ask which observation would distinguish different causes. Keep the question about evidence rather than blame. Use the supplied fictional records when observation is impractical.

In Topic 4.2, model the causal loop slowly. Ask one pupil to start with an increase and another to trace the next effect. A common difficulty is treating a negative arrow as an undesirable action. Restate the meaning as an opposite direction of change. Only name the loop after tracing the final effect. Invite pupils to challenge whether an arrow fits their school, while retaining the distinction between a proposed model and measured evidence.

For futures discussion, write "if" beside every scenario. A confident prediction is not necessarily better reasoning than a qualified account. Ask, "Whose needs make this future preferable, and who might disagree?" Use fictional roles so pupils do not have to reveal household income, access to containers or family routines.

In Topic 4.3, model the exit response before discussing the activities. Ask trainees to identify where each activity contributes to the intended evidence. Preserve the individual check if time becomes short. Use written, oral or pointed-and-explained responses with the same criteria. Group roles should distribute thinking, not leave one child calculating and another decorating throughout.

## Practical work

The three collaborative activities can be completed with a board and existing notebooks. Use pairs for plan audits and groups of three or four for model revision. No purchases, internet or field collection are required. Children should not handle mixed waste or approach unfamiliar adults. Use clean, anonymous samples and invented records; adults retain responsibility for waste handling and school routines.

Allow discussion in familiar languages before trainees state their main reasoning in plain English. A pupil who needs help reading a table can still compare the quantities when they are read aloud. Keep the cognitive demand while adapting the representation. Practicum suggestions are bounded discussions of existing classroom work, not a requirement to organise a separate visit.

After group presentations, ask each trainee to name the evidence that changed one design choice. Record whether the next explanation needs to address causal certainty, loop direction or outcome alignment.
