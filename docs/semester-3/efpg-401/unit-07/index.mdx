# Assessment

Assessment is how a teacher finds out what pupils have learned and how well they can use English. In this unit you learn to construct two kinds of test for primary English: objective-type tests, where each item has one fixed answer, and subjective-type tests, where pupils write longer answers and the teacher judges them with a rubric. You will write multiple-choice, true/false, matching and fill-in-the-blank items, and you will build an analytic marking rubric for an essay question.

## Unit learning outcomes

By the end of this unit, you will be able to:

1. Define an objective-type test and construct multiple-choice, true/false, matching and fill-in-the-blank items that match a lesson outcome. *(Remember, Apply; SLO:EFPG-401-7-1)*
2. Explain how to write a good multiple-choice item with a clear stem, one fixed key and plausible distractors. *(Understand, Apply; SLO:EFPG-401-7-1)*
3. Define a subjective-type test and distinguish it from an objective-type test on what it measures, how it is marked and how reliable it is. *(Understand, Analyze; SLO:EFPG-401-7-1)*
4. Construct an analytic marking rubric and a mark scheme that make essay marking fair and consistent. *(Apply, Create; SLO:EFPG-401-7-1)*

## Prerequisite knowledge

Unit 5 (lesson planning). You need to be able to state a lesson outcome in measurable terms, because every test item must match an outcome. If you are not yet comfortable writing an outcome such as "Pupils can use the past tense correctly in five sentences", review Unit 5 before starting this unit.

## In this unit

1. [Constructing objective-type tests](./topic-01) - what an objective-type test is, four common objective item types, and a step-by-step routine for writing a good multiple-choice item.
2. [Constructing subjective-type tests](./topic-02) - what a subjective-type test is, how it compares with an objective test, and how to mark an essay fairly with an analytic rubric.

## How to use this unit

Study the two topics in order. Each topic opens with a real classroom situation, explains the ideas with worked examples, and gives you a collaborative activity and retrieval checks. Complete the self-assessment checklist before moving on. At the end, the unit assessment asks you to construct a short English test with both item types and a marking rubric.
