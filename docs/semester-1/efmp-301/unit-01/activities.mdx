# Activities

## Activity 1: Spot the learning

In pairs, describe a recent lesson and identify one moment where real learning happened.
Explain what the teacher did that helped.

## Activity 2: Plan a small change

Choose one idea from the unit and describe one change you would make to a lesson to help
students learn better.
