# Summative Assessment

## End-of-unit question

Read the short description your teacher provides of a teacher's classroom practice. Analyze
their effectiveness using this unit's components:

- Which personal qualities (patience, resilience, adaptability, etc.) does the description show,
  and which are missing or unclear?
- How would you describe their verbal and non-verbal communication, based on the details given?
- Which of the five evolving roles (facilitator, researcher, change agent, moral agent,
  life-long learner) does their practice reflect, and why? Justify your answer using specific
  details from the description.
