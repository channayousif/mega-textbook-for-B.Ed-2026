# Activities

## Activity 1: Map a practice to a domain

In pairs, choose one classroom practice you have seen or can imagine (for example, giving
feedback on written work, managing group work, planning a lesson). Discuss which domain of
professional standards from this unit it best fits under, and describe one indicator that
practice would need to show to count as strong performance in that domain.

## Activity 2: Standards beyond the classroom

In pairs, discuss: why might a licensing or certification system want to use the same standards
that guide day-to-day teaching, rather than a separate set of criteria? Name one advantage and
one risk of tying appraisal directly to these standards.
