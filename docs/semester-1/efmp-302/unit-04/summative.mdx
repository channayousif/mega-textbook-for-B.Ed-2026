# Summative Assessment

## End-of-unit question

Read the short description your teacher provides of a teacher's classroom practice. Analyze it
against this unit's standards framework:

- Which domain(s) of professional standards does this practice relate to most directly?
- Identify at least one specific indicator the description does or does not show evidence of, and
  explain your reasoning using details from the description.
- If this practice were reviewed as part of a formal appraisal, what would it suggest about this
  teacher's readiness for licensing or certification at this stage? Justify your answer.
