# Summative Assessment

## End-of-unit question

Read the classroom-challenge scenario your teacher provides. Analyze it using this unit's ideas:

- Which specific challenges from this unit does the scenario show - workload/burnout, a
  multilingual or multi-grade classroom, resource limitations, digital-age pressures, or
  others?
- Propose one growth-oriented response to the situation, and justify why it is likely to help,
  using details from the scenario rather than a generic solution.
