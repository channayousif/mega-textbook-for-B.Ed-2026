# Summative Assessment

## End-of-unit question

Read the short description your teacher provides of a teacher's classroom practice. Analyze it
against this unit's four features of a profession (specialized training, a body of knowledge, a
code of conduct, accountability to a professional community) and against the industrial-vs-
inquiry distinction:

- Which features of a profession does the description show clearly, and which are unclear or
  missing?
- Does the described practice sit closer to the industrial model or the inquiry-based model?
  Justify your answer using specific details from the description, not just a general impression.
