# Cyber security and Data Protection

A teacher's phone holds the class group, the marks sheet, parent contacts and the school's
notices. One careless tap can leak all of it. This unit is the course's insurance policy:
the threats that actually reach ordinary users in Pakistan, the habits that stop most of
them, the trail you leave online without noticing, the craft of passwords and
authentication, what "the cloud" really is, and what protecting personal data means in a
school, where the data belongs mostly to children.

## Unit learning outcomes

By the end of this unit you should be able to:

- Identify common **cyber threats** (malware, phishing, social engineering) and the
  **online security practices** that defend against them.
- Explain what a **digital footprint** is, how it grows, and how to manage it.
- Apply good **password management** and explain how **authentication** works.
- Explain **cloud computing** basics using the standard definition.
- Analyse **privacy and data protection** issues in a school setting.

## Prerequisite knowledge

Units 1 to 3. No technical background beyond everyday phone and internet use.

## How to use this unit

The four topics build a single skill: seeing the invisible. Threats, footprints and cloud
storage are all things you cannot touch, so each topic pairs them with something concrete -
a message you can inspect, a search of your own name, a real login screen. Do those
concrete steps; they are the unit. And note that this unit's habits protect you immediately:
the password you improve this week is safer this week.
