# Ethical and Responsible Use of ICT

Unit 4 taught you to protect yourself and your pupils. This unit asks a different
question: not "how do I stay safe?" but "what is the right thing to do?" A teacher who
copies a worksheet from the internet without credit, forwards a pupil's photo to a
group, or types a careless reply in a parents' forum is not unsafe - they are
irresponsible, and pupils copy what they see. This unit covers the four faces of
responsible use: citizenship (who you are online), etiquette (how you behave),
intellectual property (whose work you use), and plagiarism (how to use it honestly).

## Unit learning outcomes

By the end of this unit you should be able to:

- Explain <Glossary term="Digital citizenship">digital citizenship</Glossary> and its
  dimensions, and name the rights and responsibilities it carries.
- Apply <Glossary term="Netiquette">netiquette</Glossary> rules to email, class chats and
  forums.
- Explain <Glossary term="Intellectual property">intellectual property</Glossary> rights,
  including copyright, and judge when a use is fair.
- Recognise <Glossary term="Plagiarism">plagiarism</Glossary> in its common forms and
  apply the habits that avoid it.

## How to use this unit

Three topics, one arc: identity, behaviour, honesty. Each ends with habits you can adopt
the same day. The summative task of the whole unit is a class code of responsible ICT
use - start collecting material for it from Topic 5.1 onwards, because every topic feeds
it.
