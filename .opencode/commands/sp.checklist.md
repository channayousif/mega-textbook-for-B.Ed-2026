# /sp.checklist

Create a checklist for a feature or task.

## When to Use

When user requests a checklist for a feature or task.

## Process

1. Read the relevant spec/plan/tasks
2. Identify checklist items from requirements
3. Organize by category
4. Number items sequentially
5. Write to `specs/<feature>/checklist.md` using template from `.specify/templates/checklist-template.md`

## Output

- Checklist written to `specs/<feature>/checklist.md`
- Format: `[CHK001] Description`
