# Grade submissions

Open an assignment's grading queue from its class page to see every actively
enrolled student, each shown as not-yet-submitted, submitted, late, or
already graded.

## Grading and returning

Entering a mark and feedback returns the submission to the student in the
same action - there is no separate "save draft" step. A mark can't exceed
the assignment's own maximum; the system rejects an out-of-range entry and
asks for a valid one. You can go back and correct an already-returned grade
at any time; the student's next visit shows the corrected value.

## Tombstoned students

If a student's account has since been deleted, their past submissions and
grades remain in the gradebook exactly as they were, just displayed without
identifying them by name.

## Answer keys and rubrics

If you hold the verified-teacher capability, the official correct-answer
reference or marking rubric for a formative or summative unit item is
available directly from the grading queue - see
[Verified-teacher material](../verified-teacher-material) for what this
capability covers and how to get it.
