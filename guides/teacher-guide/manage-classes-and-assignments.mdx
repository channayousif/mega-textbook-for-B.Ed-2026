# Manage classes and assignments

Your classes and assignments live under "Classes" (`/app/classes`), reachable
from the navbar once you're signed in as a teacher.

## Classes

Create a class with a course code, name, and term label. Each class gets a
join code your students use to enrol themselves — you can reissue a new code
at any time (the old one stops working immediately) or revoke it entirely
without affecting students already enrolled. A class can be archived once its
term ends, and reactivated later if you're still an eligible teacher; an
archived class becomes fully read-only.

## Roster

Each class has a roster of enrolled students. You can remove a student (their
past submissions and grades stay intact, just marked as no longer active) and
restore a removed student later — a student cannot rejoin a class they were
removed from just by re-entering the join code.

## Assignments

From a class, create an assignment drawn from a unit's activity, formative,
or summative item — or a custom assignment with no unit attached. Set a due
date, a maximum mark, and whether late submissions are still accepted. You
can publish or unpublish an assignment at any time, including after students
have already submitted work; unpublishing never touches existing submissions
or grades. Quizzes are a separate assignment type, scored automatically from
a unit's question bank — no manual grading needed for those.

## Gradebook

A full gradebook view and a downloadable spreadsheet export are both
available from the class page — every student against every assignment,
including students who have since been removed, so nothing in the historical
record disappears.
