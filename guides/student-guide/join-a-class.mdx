# Join a class

Your teacher will give you a short join code for their class. To use it:

1. Go to **Classes** from the app navigation and choose "Join a class."
2. Enter the code exactly as given.
3. If the code is valid, you're enrolled immediately and the class appears
   in your list - including on your dashboard's Home area.

If the code doesn't work, double-check it with your teacher - the same
message appears whether a code was mistyped, has expired, or belongs to an
archived class, so nothing about *why* it failed is revealed to a stranger
guessing codes.

If you were previously removed from a class by your teacher, re-entering
the same code won't re-add you - ask your teacher to restore you instead.
