# Human review checklist (shown at each gate in the Studio; ticks saved into approvals.*.checklist)

Adapted from the shared textbook-video-studio pack.

## Script gate
- [ ] Source is the exact lesson URL; snapshot hash recorded.
- [ ] Every claim maps to a source excerpt; no invented STEDA licence rules.
- [ ] Natural, accurate Urdu in Urdu script (not Roman Urdu).
- [ ] One idea; example fits Sindh classrooms; CTA ≤6 s and points to this page.

## Asset gate
- [ ] Spoken Urdu pronunciation and pacing acceptable.
- [ ] Same character, outfit, set and art style throughout.
- [ ] Every asset has a rights/consent note (human narrator consent if used).
- [ ] No legible AI-generated text, logos or watermarks in clips/images.

## Render gate
- [ ] Captions read right-to-left correctly in the exported MP4 (checked at phone size).
- [ ] Nothing important hidden under platform UI (safe zones).
- [ ] End card shows textbook.com.pk and the matching lesson URL.
- [ ] Plays end to end; 9:16; audio present; SRT/VTT match.

## Publish (per platform)
- [ ] Platform's AI/synthetic-content disclosure checked and applied in its upload screen (rules differ per platform and change - check current settings each time).
- [ ] Link/UTM correct; subtitle file attached where supported.
