# Modified package assessment - v1.4

## Findings
- The incoming archive contains 90 entries and predominantly **specifications**, Claude Markdown skills/commands, JSON schemas, an HTML prototype and a simple installer, rather than a running video app.
- Architectural strengths retained: SDD gate discipline; Urdu-only identity; manual-subscription provider configuration; three owner approvals; source snapshots; Remotion puppet animation; separate Docusaurus subproject; reusable Claude skills; voice benchmark; phased Studio.
- Risk: installer previously skipped conflicting existing files, which could silently leave a mixed-version installation. Replaced with fail-closed conflict detection and SHA-256 identical-file checks.
- Risk: existing path symlinks could redirect file copying outside the repo. Added symlink validation for installer source and destination traversal.
- Risk: approvals specify hash binding but the dependency/invalidation contract was not precise enough. Added canonical digest rules and dependency graph with testable invalidation examples.
- Risk: rights and narration consent are important for advertising-supported educational content. Added mandatory publish gate and explicit scope.
- Risk: static Studio design must not be mistaken for operational software. Added security acceptance tests for its eventual backend.
- Risk: Urdu captions can pass a DOM preview but fail an encoded render. Added encoded-frame visual verification tests.

## Adopted improvements
1. Strict fail-closed non-destructive installer.
2. Read-only package audit utility.
3. VS-004: production integrity, reproducible digests, accessibility, attribution, licence and consent controls.
4. More explicit integration and honest implementation status.
5. Reference links in top-level README and checklist.

## Deferred intentionally
- Paid video and voice APIs; browser-scraping subscriptions; automated publishing; background agent execution; Studio backend before CLI proof; declaring any Urdu TTS winner without audio testing.

## Validation scope
Archive files, JSON syntax, installer dry-run on an isolated fake Docusaurus Git directory, and ZIP integrity are checked. Parent textbook repository and actual Remotion output are not available in this upload, so no parent build, render, voice or server integration can be claimed.
