# Export document format

Generated by `src/lib/contentFeedback.ts`'s `exportUnitFeedback(courseCode, unitNo)` (Spec
010, T032), offered for download/copy from `admin/feedback-queue.tsx`'s "Export unit
feedback" control. Never stored - regenerated on demand from `content_feedback` rows with
`status in ('open', 'planned')`, scoped to one unit.

## Shape

```markdown
# Feedback export

## <repo-relative-path-1>

> <quoted passage of item 1>

<comment of item 1>

<comment of item 2 - whole-page, no blockquote>

## <repo-relative-path-2>

> <quoted passage of item 3>

<comment of item 3>
```

- **One `##` heading per affected file**, holding a repo-relative path exactly as it
  appears in the repository (e.g. `docs/semester-1/efmp-302/unit-01/topic-01.mdx`,
  `docs/semester-1/efmp-302/unit-01/index.mdx`, `docs/semester-1/efmp-302/course-review.mdx`).
  Multiple items on the same file are grouped under one heading, in filing order.
- **A blockquote (`> ...`) immediately below the heading** is a passage-scoped item's
  quoted text, verbatim from the moment it was filed - it may no longer match the file's
  current text (FR-021: the quote stays as originally filed, even after the underlying
  topic text changes). See `stale-passage-handling.md` for what to do when it doesn't
  match.
- **The paragraph immediately following** (whether or not there was a blockquote above it)
  is that item's comment - the actual ask. A comment with no preceding blockquote in this
  item's slot is whole-page feedback: general commentary on the file, not anchored to a
  specific sentence.
- **No page body text is ever included** (FR-022) - nothing in this document came from the
  topic/unit file's own prose except the quoted passages readers themselves selected. Do
  not expect surrounding context beyond what a blockquote itself contains; re-read the
  actual file (step 2 of SKILL.md) to see the passage in place.
- **A unit with zero open/planned items** produces a document containing only the heading
  and a "No open or planned feedback items for this unit." line - treat this as nothing to
  do, not an error.
- **Idempotent**: re-exporting the same unit with no queue change in between returns the
  same items again, in the same grouping. Re-running this skill against an unchanged export
  should therefore make no new edits beyond what a prior run already made (its edits already
  addressed the comments; re-verify rather than re-editing).
